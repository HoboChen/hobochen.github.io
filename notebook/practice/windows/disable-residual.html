关闭残余 Windows 组件

在 disable-defender.ps1 + disable-telemetry.ps1 基线之外，额外关闭： Recall / Copilot / Windows AI / Windows AI Fabric、MDM 自动注册、SysMain (Superfetch)、Windows Search 索引、Delivery Optimization (P2P 上传)。

前置条件

  • 以 管理员身份 运行 PowerShell
  • 建议先执行 关闭 Windows 遥测 和 关闭 Windows Defender，再处理本页的残余组件。
  • 回滚命令会删除整份本地 Registry.pol。如果机器上还有其他本地组策略，先备份 %SystemRoot%\System32\GroupPolicy。
Install-Module -Name PolicyFileEditor -Force -Scope CurrentUser

涵盖项目

组策略项

类别 策略 / 操作 方式
Recall / Windows AI DisableAIDataAnalysis=1, TurnOffSavedSnapshots=1, AllowRecallEnablement=0 Group Policy (Machine + User)
Windows Copilot TurnOffWindowsCopilot=1 Group Policy (Machine + User)
Search Box 网络建议 DisableSearchBoxSuggestions=1 Group Policy
MDM 自动注册 AutoEnrollMDM=0, DisableRegistration=1 Group Policy
Cortana / Web Search AllowCortana=0, DisableWebSearch=1, ConnectedSearchUseWeb=0, AllowSearchToUseLocation=0 Group Policy
Delivery Optimization DODownloadMode=0 (HTTP only, 无 P2P), Max bandwidth=0 Group Policy

禁用的服务

服务名 说明
WSAIFabricSvc Windows AI Fabric Service — 会拉起 WorkloadsSessionHost.exe / WorkloadsSessionManager.exe，可能出现内存泄漏或 NPU/GPU 后台占用
SysMain Superfetch / 预读 — 在 NVMe 上净负收益
WSearch Windows Search 索引器
DoSvc Delivery Optimization (Windows Update P2P)

禁用的计划任务

任务路径 说明
\Microsoft\Windows\EnterpriseMgmt\* MDM 设备管理
\Microsoft\Windows\Management\Provisioning\* 设备预配
\Microsoft\Windows\Workplace Join\* Azure AD / Workplace Join
Recall 可选功能 (Disable-WindowsOptionalFeature -FeatureName Recall) Win11 24H2+

移除的 AppX 包

  • Microsoft.Copilot*, Windows.Copilot*
  • Microsoft.Windows.Ai*, Microsoft.Windows.Recall*
  • MicrosoftWindows.Client.AIX*
  • 包括 provisioned (模板) 包 — 新建用户也不再获得

powershell -ExecutionPolicy Bypass -File "$HOME\Desktop\disable-residual.ps1"

#Requires -RunAsAdministrator

$ErrorActionPreference = "Stop"

$script:ResidualTranscriptPath = Join-Path $PSScriptRoot "disable-residual.log"
Start-Transcript -Path $script:ResidualTranscriptPath -Force | Out-Null

function Write-Step {
    param([string]$Message)
    Write-Host "`n$Message" -ForegroundColor Yellow
}

function Write-Ok {
    param([string]$Message)
    Write-Host "  [+] $Message" -ForegroundColor Gray
}

function Write-Skip {
    param([string]$Message)
    Write-Host "  [~] $Message" -ForegroundColor DarkGray
}

function Ensure-PolicyFileEditor {
    Write-Step "[0/5] Checking PolicyFileEditor module..."
    if (-not (Get-Module -ListAvailable -Name PolicyFileEditor)) {
        Write-Host "  Installing PolicyFileEditor..." -ForegroundColor Gray
        [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
        Install-Module -Name PolicyFileEditor -Force -Scope CurrentUser -AllowClobber
    }
    Import-Module PolicyFileEditor
    Write-Ok "PolicyFileEditor is ready."
}

function Set-PolicyDWord {
    param(
        [Parameter(Mandatory)] [string]$Path,
        [Parameter(Mandatory)] [string]$Key,
        [Parameter(Mandatory)] [string]$ValueName,
        [Parameter(Mandatory)] [int]$Data
    )
    Set-PolicyFileEntry -Path $Path -Key $Key -ValueName $ValueName -Data $Data -Type DWord
}

function Disable-ServiceIfPresent {
    param(
        [Parameter(Mandatory)] [string]$Name,
        [Parameter(Mandatory)] [string]$Description
    )
    $service = Get-Service -Name $Name -ErrorAction SilentlyContinue
    if (-not $service) {
        Write-Skip "$Name not found; skipped."
        return
    }
    if ($service.Status -eq "Running") {
        Stop-Service -Name $Name -Force -ErrorAction SilentlyContinue
    }
    Set-Service -Name $Name -StartupType Disabled -ErrorAction SilentlyContinue
    Write-Ok "$Description ($Name) stopped and disabled."
}

function Stop-ProcessByNameIfPresent {
    param(
        [Parameter(Mandatory)] [string[]]$Name,
        [Parameter(Mandatory)] [string]$Description
    )
    $processes = Get-Process -Name $Name -ErrorAction SilentlyContinue
    if (-not $processes) {
        Write-Skip "$Description not running; skipped."
        return
    }
    $processes | Stop-Process -Force -ErrorAction SilentlyContinue
    Write-Ok "$Description processes stopped."
}

function Disable-TaskTreeIfPresent {
    param([Parameter(Mandatory)] [string]$TaskPath)

    $tasks = Get-ScheduledTask -TaskPath $TaskPath -ErrorAction SilentlyContinue
    if (-not $tasks) {
        Write-Skip "$TaskPath has no tasks; skipped."
        return
    }
    foreach ($t in $tasks) {
        try {
            Disable-ScheduledTask -TaskPath $t.TaskPath -TaskName $t.TaskName -ErrorAction SilentlyContinue | Out-Null
            $check = Get-ScheduledTask -TaskPath $t.TaskPath -TaskName $t.TaskName -ErrorAction SilentlyContinue
            if ($check -and $check.State -eq "Disabled") {
                Write-Ok "$($t.TaskPath)$($t.TaskName) disabled."
            } else {
                Write-Skip "$($t.TaskPath)$($t.TaskName) state: $($check.State)."
            }
        } catch {
            Write-Skip "$($t.TaskPath)$($t.TaskName) failed: $($_.Exception.Message)"
        }
    }
}

Write-Host "=== Disabling Residual Windows Components ===" -ForegroundColor Cyan

Ensure-PolicyFileEditor

$machinePolPath = "$env:SystemRoot\System32\GroupPolicy\Machine\Registry.pol"
$userPolPath    = "$env:SystemRoot\System32\GroupPolicy\User\Registry.pol"

$machinePolDir = Split-Path $machinePolPath
$userPolDir    = Split-Path $userPolPath
if (-not (Test-Path $machinePolDir)) { New-Item -Path $machinePolDir -ItemType Directory -Force | Out-Null }
if (-not (Test-Path $userPolDir))    { New-Item -Path $userPolDir    -ItemType Directory -Force | Out-Null }

# ---------------------------------------------------------------
# Step 1: Disable Recall, Copilot, and on-device AI data analysis
# ---------------------------------------------------------------
Write-Step "[1/5] Disabling Recall / Copilot / Windows AI..."

$aiKey = "SOFTWARE\Policies\Microsoft\Windows\WindowsAI"
Set-PolicyDWord -Path $machinePolPath -Key $aiKey -ValueName "DisableAIDataAnalysis"        -Data 1
Set-PolicyDWord -Path $machinePolPath -Key $aiKey -ValueName "TurnOffSavedSnapshots"        -Data 1
Set-PolicyDWord -Path $machinePolPath -Key $aiKey -ValueName "AllowRecallEnablement"        -Data 0
Set-PolicyDWord -Path $userPolPath    -Key $aiKey -ValueName "DisableAIDataAnalysis"        -Data 1
Set-PolicyDWord -Path $userPolPath    -Key $aiKey -ValueName "TurnOffSavedSnapshots"        -Data 1
Write-Ok "Recall (AI data analysis / snapshots) policies written."

$copilotKey = "SOFTWARE\Policies\Microsoft\Windows\WindowsCopilot"
Set-PolicyDWord -Path $machinePolPath -Key $copilotKey -ValueName "TurnOffWindowsCopilot"   -Data 1
Set-PolicyDWord -Path $userPolPath    -Key $copilotKey -ValueName "TurnOffWindowsCopilot"   -Data 1
Write-Ok "Windows Copilot policies written."

$explorerKey = "SOFTWARE\Policies\Microsoft\Windows\Explorer"
Set-PolicyDWord -Path $machinePolPath -Key $explorerKey -ValueName "DisableSearchBoxSuggestions" -Data 1
Write-Ok "Search-box web suggestions disabled."

# Remove AppX packages (best-effort)
$aiPackagePatterns = @(
    "*Microsoft.Copilot*",
    "*Windows.Copilot*",
    "*Microsoft.Windows.Ai*",
    "*Microsoft.Windows.Recall*",
    "*MicrosoftWindows.Client.AIX*"
)
foreach ($pattern in $aiPackagePatterns) {
    $pkgs = Get-AppxPackage -AllUsers -Name $pattern -ErrorAction SilentlyContinue
    foreach ($p in $pkgs) {
        try {
            Remove-AppxPackage -Package $p.PackageFullName -AllUsers -ErrorAction Stop
            Write-Ok "Removed AppX: $($p.Name)"
        } catch {
            Write-Skip "Could not remove $($p.Name): $($_.Exception.Message)"
        }
    }
    $prov = Get-AppxProvisionedPackage -Online | Where-Object { $_.DisplayName -like $pattern }
    foreach ($p in $prov) {
        try {
            Remove-AppxProvisionedPackage -Online -PackageName $p.PackageName -AllUsers -ErrorAction Stop | Out-Null
            Write-Ok "Removed provisioned: $($p.DisplayName)"
        } catch {
            Write-Skip "Could not remove provisioned $($p.DisplayName): $($_.Exception.Message)"
        }
    }
}

# Optional feature (Win11 24H2+) - tolerate absence
try {
    $feat = Get-WindowsOptionalFeature -Online -FeatureName Recall -ErrorAction SilentlyContinue
    if ($feat -and $feat.State -eq "Enabled") {
        Disable-WindowsOptionalFeature -Online -FeatureName Recall -NoRestart -ErrorAction SilentlyContinue | Out-Null
        Write-Ok "Optional feature 'Recall' disabled."
    } else {
        Write-Skip "Optional feature 'Recall' not present/enabled."
    }
} catch {
    Write-Skip "Recall optional feature check failed: $($_.Exception.Message)"
}

# Windows AI Fabric service can keep WorkloadsSessionHost.exe resident.
Disable-ServiceIfPresent -Name "WSAIFabricSvc" -Description "Windows AI Fabric service"
Stop-ProcessByNameIfPresent -Name @("WorkloadsSessionHost", "WorkloadsSessionManager") -Description "Windows Workloads session host/manager"

# ---------------------------------------------------------------
# Step 2: Disable MDM enrollment surface
# ---------------------------------------------------------------
Write-Step "[2/5] Disabling MDM / Workplace Join task surface..."

Disable-TaskTreeIfPresent -TaskPath "\Microsoft\Windows\EnterpriseMgmt\"
Disable-TaskTreeIfPresent -TaskPath "\Microsoft\Windows\Management\Provisioning\"
Disable-TaskTreeIfPresent -TaskPath "\Microsoft\Windows\Workplace Join\"

# Block automatic MDM enrollment via policy (no-op if already disabled)
$mdmKey = "SOFTWARE\Policies\Microsoft\Windows\CurrentVersion\MDM"
Set-PolicyDWord -Path $machinePolPath -Key $mdmKey -ValueName "AutoEnrollMDM"           -Data 0
Set-PolicyDWord -Path $machinePolPath -Key $mdmKey -ValueName "DisableRegistration"     -Data 1
Write-Ok "MDM auto-enrollment policy written."

# ---------------------------------------------------------------
# Step 3: Disable SysMain (Superfetch) - net negative on NVMe
# ---------------------------------------------------------------
Write-Step "[3/5] Disabling SysMain..."
Disable-ServiceIfPresent -Name "SysMain" -Description "SysMain / Superfetch"

# ---------------------------------------------------------------
# Step 4: Disable Windows Search indexing service
# ---------------------------------------------------------------
Write-Step "[4/5] Disabling Windows Search (WSearch) indexer..."
Disable-ServiceIfPresent -Name "WSearch" -Description "Windows Search indexer"

# Also disable Cortana / web search in Start menu via policy
$searchKey = "SOFTWARE\Policies\Microsoft\Windows\Windows Search"
Set-PolicyDWord -Path $machinePolPath -Key $searchKey -ValueName "AllowCortana"          -Data 0
Set-PolicyDWord -Path $machinePolPath -Key $searchKey -ValueName "DisableWebSearch"      -Data 1
Set-PolicyDWord -Path $machinePolPath -Key $searchKey -ValueName "ConnectedSearchUseWeb" -Data 0
Set-PolicyDWord -Path $machinePolPath -Key $searchKey -ValueName "AllowSearchToUseLocation" -Data 0
Write-Ok "Cortana, web search, and location-aware search policies written."

# ---------------------------------------------------------------
# Step 5: Disable Delivery Optimization (P2P update uploads)
# ---------------------------------------------------------------
Write-Step "[5/5] Disabling Delivery Optimization..."

$doKey = "SOFTWARE\Policies\Microsoft\Windows\DeliveryOptimization"
Set-PolicyDWord -Path $machinePolPath -Key $doKey -ValueName "DODownloadMode"         -Data 0
Set-PolicyDWord -Path $machinePolPath -Key $doKey -ValueName "DOMaxBackgroundDownloadBandwidth" -Data 0
Set-PolicyDWord -Path $machinePolPath -Key $doKey -ValueName "DOMaxForegroundDownloadBandwidth" -Data 0
Write-Ok "Delivery Optimization policy: HTTP only, no peer-to-peer."

Disable-ServiceIfPresent -Name "DoSvc"  -Description "Delivery Optimization service"

# ---------------------------------------------------------------
# Apply Group Policy
# ---------------------------------------------------------------
Write-Step "Applying Group Policy changes..."
gpupdate /force /wait:0 | Out-Host
Write-Ok "Group Policy update requested."

Write-Host "`n=== Residual components disabled ===" -ForegroundColor Cyan
Write-Host "A reboot is recommended for all changes to take full effect." -ForegroundColor Yellow
Stop-Transcript | Out-Null
Write-Host "Log written to $script:ResidualTranscriptPath" -ForegroundColor Yellow

预期结果

  • WSAIFabricSvc, SysMain, WSearch, DoSvc : Stopped / Disabled
  • WorkloadsSessionHost.exe, WorkloadsSessionManager.exe : 无运行实例
  • EnterpriseMgmt, Workplace Join 任务: 全部 Disabled 或不存在
  • AppX 查询: 无结果 (Copilot/Recall 已移除)
  • 组策略表中可见 TurnOffWindowsCopilot=1, DisableAIDataAnalysis=1, DODownloadMode=0 等

副作用 / 回滚提醒

关闭项 副作用
WSAIFabricSvc Recall、Live Captions、语义搜索、部分 Windows AI / NPU 功能可能不可用；累积更新可能重新启用
WSearch 开始菜单搜索 / 资源管理器搜索变慢 (全盘扫描而非索引)；Outlook 经典版搜索失效
SysMain 冷启动应用稍慢；NVMe 上几乎无感知
DoSvc Windows Update 仅走 HTTP，无 LAN/Internet peer 加速
Copilot / Recall AppX 移除 累积更新可能重新植入 provisioned 包 — 周期性复跑本脚本
MDM 任务禁用 若日后加入 Intune/AAD 需手动重新启用相关任务

回滚

删除组策略文件并重新启用服务：

会删除本机所有本地组策略文件。若有其他本地策略，先备份 %SystemRoot%\System32\GroupPolicy。

Remove-Item "$env:SystemRoot\System32\GroupPolicy\Machine\Registry.pol" -Force
Remove-Item "$env:SystemRoot\System32\GroupPolicy\User\Registry.pol" -Force
gpupdate /force

'WSAIFabricSvc','SysMain','WSearch','DoSvc' | ForEach-Object {
    Set-Service $_ -StartupType Automatic -EA SilentlyContinue
    Start-Service $_ -EA SilentlyContinue
}
