使用白霜拼音 rime_frost 全拼方案，搭配万象 LTS 简体语法模型。本文提供安装、同步配置和重新部署的命令骨架；<…> 替换为实际路径，日常改配置只需同步 custom 文件并部署。

配置入口

文件 当前设置
default.custom.yaml 只启用白霜；Ctrl+Shift+反引号打开 Rime 内部选单
rime_frost.custom.yaml 每页 5 个候选；en / eng、in / ing 双向模糊音；万象模型与上下文建议
squirrel.custom.yaml macOS 字号 18，标签与注释字号 13，间距 3、行距 1、圆角 6
weasel.custom.yaml Windows metroblue 主题、拼音内嵌显示

将第 3 节给出的 *.custom.yaml 保存到输入法用户目录；若本机已有同名文件，先比较并合并。补丁放在 patch: 下，speller/algebra/+ 表示追加规则，不替换上游全部拼写规则。

基础：Rime 定制与补丁。

1. 安装前端

只在首次安装或需要升级时执行。

系统 前端 默认用户目录
Linux（GNOME） IBus Rime ${XDG_CONFIG_HOME:-~/.config}/ibus/rime
macOS 鼠须管 Squirrel ~/Library/Rime
Windows 小狼毫 Weasel %APPDATA%\Rime 
# Debian / Ubuntu GNOME
sudo apt update
sudo apt install -y ibus-rime librime-plugin-octagram

# 受支持的现代 macOS；旧 Mac 见文末兼容记录
brew install --cask squirrel-app
# Windows
winget install --id Rime.Weasel --exact

预期：系统输入法设置中能添加 Rime / 鼠须管 / 小狼毫。万象模型需要 librime 支持 octagram；安装前端不等于已经装好白霜资源。

基础：IBus Rime、鼠须管、小狼毫。

2. 白霜资源与语言模型

首次安装或升级资源时执行；只调整候选数、模糊音或外观时跳过。白霜需完整复制，包括 lua/、词典目录和依赖方案，不能只复制主 schema。

Linux / macOS

先设置实际目录，以下步骤在同一终端执行：

RIME_USER_DIR="$HOME/Library/Rime"  # macOS
# Linux 改为：RIME_USER_DIR="${XDG_CONFIG_HOME:-$HOME/.config}/ibus/rime"
FROST_TMP="$(mktemp -d)"

git clone --depth 1 https://github.com/gaboolic/rime-frost.git "$FROST_TMP/frost"
mkdir -p "$RIME_USER_DIR"
rsync -a \
  --exclude='.git' --exclude='.github' --exclude='*.custom.yaml' \
  --exclude='*.userdb*' --exclude='custom_phrase.txt' \
  --exclude='user.yaml' --exclude='installation.yaml' \
  --exclude='sync/' --exclude='build/' \
  "$FROST_TMP/frost/" "$RIME_USER_DIR/"
curl -fL \
  https://github.com/amzxyz/RIME-LMDG/releases/download/LTS/wanxiang-lts-zh-hans.gram \
  -o "$RIME_USER_DIR/wanxiang-lts-zh-hans.gram"

Windows

$RimeDir = "$env:APPDATA\Rime"  # 自定义安装目录时替换
$FrostTemp = Join-Path $env:TEMP ('rime-frost-' + [guid]::NewGuid())

git clone --depth 1 https://github.com/gaboolic/rime-frost.git $FrostTemp
if ($LASTEXITCODE -ne 0) { throw '白霜下载失败' }
New-Item -ItemType Directory -Force $RimeDir | Out-Null
robocopy $FrostTemp $RimeDir /E `
  /XD .git .github *.userdb sync build `
  /XF *.custom.yaml *.userdb* custom_phrase.txt user.yaml installation.yaml
if ($LASTEXITCODE -ge 8) { throw '资源复制失败' }
Invoke-WebRequest `
  -Uri 'https://github.com/amzxyz/RIME-LMDG/releases/download/LTS/wanxiang-lts-zh-hans.gram' `
  -OutFile (Join-Path $RimeDir 'wanxiang-lts-zh-hans.gram')

预期：用户目录内有 rime_frost.schema.yaml、lua/、词典目录和 wanxiang-lts-zh-hans.gram。配置的 grammar/language 为 wanxiang-lts-zh-hans；白霜自带的 zh-moqi.gram 可保留，但不是当前模型。

同步不使用 rsync --delete 或 robocopy /MIR，保留本机词库、短语和状态；任一步失败先处理错误，不继续部署。

基础：白霜资源与依赖、万象语言模型。

3. 写入配置并部署

日常修改从这里开始。将以下内容分别保存到实际输入法用户目录下的同名文件：Linux 为 ${XDG_CONFIG_HOME:-~/.config}/ibus/rime，macOS 为 ~/Library/Rime，Windows 为 %APPDATA%\Rime。前两个文件用于所有平台；后两个只保存当前平台对应的文件。已有配置先备份并合并，不覆盖本机词库、短语与 user.yaml，不直接改 build/。

default.custom.yaml：

patch:
  schema_list:
    - {schema: rime_frost}
  switcher/hotkeys:
    - Control+Shift+grave

rime_frost.custom.yaml：

patch:
  menu/page_size: 5

  speller/algebra/+:
    - derive/eng$/en/
    - derive/en$/eng/
    - derive/ing$/in/
    - derive/in$/ing/

  grammar:
    language: wanxiang-lts-zh-hans
    collocation_max_length: 5
    collocation_min_length: 2
    non_collocation_penalty: -4
    collocation_penalty: -14

  translator/contextual_suggestions: true
  translator/max_homophones: 4
  translator/max_homographs: 2

squirrel.custom.yaml：

patch:
  style/font_point: 18
  style/label_font_point: 13
  style/comment_font_point: 13
  style/spacing: 3
  style/line_spacing: 1
  style/corner_radius: 6

weasel.custom.yaml：

patch:
  style/color_scheme: metroblue
  style/inline_preedit: true

Linux / macOS

配置保存完成后，按平台重新部署。

Linux GNOME 部署：

RIME_USER_DIR="${XDG_CONFIG_HOME:-$HOME/.config}/ibus/rime"
rime_deployer --build "$RIME_USER_DIR" /usr/share/rime-data "$RIME_USER_DIR/build"
(cd "$RIME_USER_DIR" && rime_deployer --set-active-schema rime_frost)
systemctl --user restart org.freedesktop.IBus.session.GNOME.service

在 GNOME 设置中添加 Rime 输入源，Super+Space 切换。服务名按本机调整；不要用 ibus-daemon -drxR 替换 GNOME 托管的 IBus。

macOS 从鼠须管菜单选择「重新部署」，支持命令行重载的版本也可执行：

"/Library/Input Methods/Squirrel.app/Contents/MacOS/Squirrel" --reload

Windows

# 替换为实际安装版本的部署工具路径，或直接使用菜单「重新部署」
& '<小狼毫安装目录>\WeaselDeployer.exe' /deploy

预期：输入 nihao 出现「你好」，每页最多 5 个候选；Ctrl+Shift+反引号打开内部选单。模糊音与候选窗外观按上述配置生效；模型是否加载需看日志，不能只凭一个词的排序判断。

基础：Rime 用户目录与重新部署。

配置不生效时

  • 先确认实际用户目录、patch: 层级与部署日志，再查看 build/rime_frost.schema.yaml 中的生效值。
  • Lua 模块缺失：检查白霜资源是否完整，以及 librime / Lua 插件兼容性。
  • 模型未加载：检查 .gram 文件、grammar/language 和 octagram 支持。
  • 需要回退配置：恢复旧 custom 文件后重新部署；不要用旧用户数据库覆盖新学习数据。

本机兼容记录：macOS 10.9.5

据 ~/Library/Rime/INSTALL-NOTES.local.txt（2026-10-16），本机使用 Squirrel 0.9.26.2 发行包前端 + 0.16.2 发行包中的 librime 1.8.5、部署与词典工具。这是本机组合安装；前端自报版本 0.9.26.1。较新前端在此系统上因 NSTextContainer initWithSize: 崩溃，因此不执行上面的 Homebrew 安装或自动升级。日常只修改 custom 配置并部署，升级资源前核对核心兼容性。组件来源：Squirrel 官方发行包。
