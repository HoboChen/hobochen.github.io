分别调整 Windows 遥测、其他组件和 Defender，三部分可以独立执行。使用管理员 Windows PowerShell 5.1；策略是否生效取决于 Windows 版本、Edition 和组织管理状态。

Get-ComputerInfo | Select-Object WindowsProductName, WindowsVersion, OsBuildNumber
$PSVersionTable.PSVersion

完整脚本在对应章节的折叠代码块中，按说明保存到桌面后执行，不需要其他本地文件。脚本会安装并导入 PolicyFileEditor，通过 Registry.pol 写入本地组策略。当前用户偏好和应用卸载作用于运行脚本的账户；用另一个管理员账户提权时，这些操作会落到那个账户。

关闭 Windows 遥测

默认配置覆盖以下项目；不会默认关闭服务、计划任务或定位：

范围 配置
诊断数据 AllowTelemetry=0，限制诊断日志和转储收集，关闭诊断级别选择界面、变更通知及反馈提示，不发送设备名
远程配置 DisableOneSettingsDownloads=1，阻止 OneSettings 配置下载
广告与推荐 广告 ID、消费者体验、云优化内容、第三方建议、基于诊断数据的个性化体验、Spotlight
用户内容推荐 当前用户的 SubscribedContent-* 和 SilentInstalledAppsEnabled 偏好
错误报告 WER 关闭、禁止附加数据和日志；同意级别设为“始终询问”
输入隐私 手写错误报告、输入与手写数据收集、自动学习、在线语音识别
活动历史 EnableActivityFeed=0、PublishUserActivities=0、UploadUserActivities=0

Home / Pro 的 AllowTelemetry=0 会受最低支持级别限制，不能据此声称零上报。CloudContent 中部分策略只适用于 Enterprise / Education 等 Edition。ContentDeliveryManager 是版本相关的用户偏好，写入 HKCU:\Software\Microsoft\Windows\CurrentVersion\ContentDeliveryManager；输入自动学习偏好写入 HKCU:\Software\Microsoft\InputPersonalization，均与机器策略分开保存。

ConfigureWindowsSpotlight=0 才是关闭锁屏 Spotlight，2 表示强制开启。DefaultConsent=1 表示始终询问，关闭 WER 由 Disabled=1 完成；不使用未文档化的 DefaultConsent=0 来宣称“永不发送”。关闭在线语音识别会影响依赖云端识别的听写功能。

基础：诊断数据、OneSettings 与诊断策略、CloudContent / Spotlight、输入与手写数据、输入偏好与活动历史、WER 设置。

完整脚本与可选关闭项

将以下代码保存为 ~/Desktop/disable-telemetry.ps1：

disable-telemetry.ps1：诊断、推荐、输入隐私、活动历史及可选服务和任务 
#Requires -Version 5.1
#Requires -RunAsAdministrator
[CmdletBinding()]
param(
    [switch]$Compatibility,
    [switch]$Location,
    [switch]$Services,
    [switch]$Tasks,
    [switch]$LegacyAnalytics
)

$ErrorActionPreference = 'Stop'
if (-not (Get-Module -ListAvailable -Name PolicyFileEditor)) {
    Install-Module PolicyFileEditor -Scope CurrentUser -Force
}
Import-Module PolicyFileEditor
$MachinePol = "$env:SystemRoot\System32\GroupPolicy\Machine\Registry.pol"
$UserPol = "$env:SystemRoot\System32\GroupPolicy\User\Registry.pol"
$Policies = [System.Collections.Generic.List[object]]::new()
$Preferences = [System.Collections.Generic.List[object]]::new()
$ServiceNames = @()
$TaskNames = @()
$FeatureBefore = @()
$Packages = @()
$ProvisionedPackages = @()

function Add-Policy {
    param([string]$Scope, [string]$Key, [hashtable]$Values)
    foreach ($name in $Values.Keys) {
        $path = if ($Scope -eq 'Machine') { $MachinePol } else { $UserPol }
        $hive = if ($Scope -eq 'Machine') { 'HKLM:\' } else { 'HKCU:\' }
        $Policies.Add([pscustomobject]@{
            Path = $path; Key = $Key; Name = $name
            RegistryPath = $hive + $Key; Data = $Values[$name]
        })
    }
}

function Get-RegistryValueBefore {
    param([string]$Path, [string]$Name)
    if (Test-Path -LiteralPath $Path) {
        $key = Get-Item -LiteralPath $Path
        if ($key.GetValueNames() -contains $Name) {
            return [pscustomobject]@{
                Exists = $true; Type = $key.GetValueKind($Name).ToString()
                Data = $key.GetValue($Name, $null,
                    [Microsoft.Win32.RegistryValueOptions]::DoNotExpandEnvironmentNames)
            }
        }
    }
    return [pscustomobject]@{ Exists = $false; Type = $null; Data = $null }
}

$BackupLabel = 'telemetry'
$dc = 'SOFTWARE\Policies\Microsoft\Windows\DataCollection'
Add-Policy Machine $dc @{
    AllowTelemetry = 0
    DisableTelemetryOptInSettingsUx = 1
    DisableTelemetryOptInChangeNotification = 1
    DoNotShowFeedbackNotifications = 1
    LimitDiagnosticLogCollection = 1
    LimitDumpCollection = 1
    DisableOneSettingsDownloads = 1
    AllowDeviceNameInTelemetry = 0
}
if ($LegacyAnalytics) {
    # Legacy processor/analytics policies do not turn off all diagnostic data.
    Add-Policy Machine $dc @{
        AllowDesktopAnalyticsProcessing = 0
        AllowCommercialDataPipeline = 0
        LimitEnhancedDiagnosticDataWindowsAnalytics = 1
    }
}
if ($Compatibility) {
    Add-Policy Machine 'SOFTWARE\Policies\Microsoft\Windows\AppCompat' @{
        AITEnable = 0; DisableInventory = 1; DisableUAR = 1; DisablePCA = 1
    }
    Add-Policy Machine 'SOFTWARE\Policies\Microsoft\SQMClient\Windows' @{ CEIPEnable = 0 }
}

$cloud = 'SOFTWARE\Policies\Microsoft\Windows\CloudContent'
Add-Policy Machine $cloud @{
    DisableCloudOptimizedContent = 1; DisableConsumerAccountStateContent = 1
    DisableSoftLanding = 1; DisableWindowsConsumerFeatures = 1
}
Add-Policy User $cloud @{
    DisableThirdPartySuggestions = 1; DisableTailoredExperiencesWithDiagnosticData = 1
    DisableWindowsSpotlightFeatures = 1; ConfigureWindowsSpotlight = 0
}
Add-Policy Machine 'SOFTWARE\Policies\Microsoft\Windows\AdvertisingInfo' @{
    DisabledByGroupPolicy = 1
}
# These are current-user preferences, not documented CloudContent policies.
$cdm = 'HKCU:\Software\Microsoft\Windows\CurrentVersion\ContentDeliveryManager'
foreach ($name in @(
    'SubscribedContent-338388Enabled', 'SubscribedContent-338389Enabled',
    'SubscribedContent-310093Enabled', 'SubscribedContent-353698Enabled',
    'SilentInstalledAppsEnabled'
)) {
    $Preferences.Add([pscustomobject]@{ Path = $cdm; Name = $name; Data = 0 })
}

$wer = 'SOFTWARE\Policies\Microsoft\Windows\Windows Error Reporting'
Add-Policy Machine $wer @{ Disabled = 1; DontSendAdditionalData = 1; LoggingDisabled = 1 }
# 1 = always ask. Disabling reporting is done by Disabled=1, not by consent=0.
Add-Policy Machine "$wer\Consent" @{ DefaultConsent = 1; DefaultOverrideBehavior = 1 }
Add-Policy Machine 'SOFTWARE\Policies\Microsoft\Windows\HandwritingErrorReports' @{
    PreventHandwritingErrorReports = 1
}
Add-Policy Machine 'SOFTWARE\Policies\Microsoft\InputPersonalization' @{
    AllowInputPersonalization = 0
}
Add-Policy Machine 'SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\TextInput' @{
    AllowLinguisticDataCollection = 0
}
foreach ($name in @('RestrictImplicitInkCollection', 'RestrictImplicitTextCollection')) {
    $Preferences.Add([pscustomobject]@{
        Path = 'HKCU:\Software\Microsoft\InputPersonalization'; Name = $name; Data = 1
    })
}
if ($Location) {
    Add-Policy Machine 'SOFTWARE\Policies\Microsoft\Windows\LocationAndSensors' @{
        DisableLocation = 1; DisableWindowsLocationProvider = 1; DisableLocationScripting = 1
    }
}
Add-Policy Machine 'SOFTWARE\Policies\Microsoft\Windows\System' @{
    EnableActivityFeed = 0; PublishUserActivities = 0; UploadUserActivities = 0
}
if ($Services) {
    $ServiceNames = @(
        'DiagTrack', 'whesvc', 'InventorySvc', 'diagsvc', 'PcaSvc', 'dmwappushservice'
    )
}
if ($Tasks) {
    $TaskNames = @(
        '\Microsoft\Windows\Application Experience\Microsoft Compatibility Appraiser',
        '\Microsoft\Windows\Application Experience\MareBackup',
        '\Microsoft\Windows\Application Experience\PcaPatchDbTask',
        '\Microsoft\Windows\Application Experience\SdbinstMergeDbTask',
        '\Microsoft\Windows\Application Experience\StartupAppTask',
        '\Microsoft\Windows\Autochk\Proxy',
        '\Microsoft\Windows\Customer Experience Improvement Program\Consolidator',
        '\Microsoft\Windows\Customer Experience Improvement Program\UsbCeip',
        '\Microsoft\Windows\DiskDiagnostic\Microsoft-Windows-DiskDiagnosticDataCollector',
        '\Microsoft\Windows\Feedback\Siuf\DmClient',
        '\Microsoft\Windows\Feedback\Siuf\DmClientOnScenarioDownload',
        '\Microsoft\Windows\Maps\MapsToastTask',
        '\Microsoft\Windows\Maps\MapsUpdateTask'
    )
}

# Finish all snapshots before changing any policy, preference, service or task.
$BackupDirectory = Join-Path $HOME ("windows-{0}-before-{1}" -f $BackupLabel,
    (Get-Date -Format 'yyyyMMdd-HHmmss-fff'))
New-Item -ItemType Directory -Path $BackupDirectory | Out-Null
$PolicyBefore = @(
    foreach ($entry in $Policies) {
        $old = $null
        if (Test-Path -LiteralPath $entry.Path) {
            $old = Get-PolicyFileEntry -Path $entry.Path -Key $entry.Key -ValueName $entry.Name
        }
        [pscustomobject]@{
            Path = $entry.Path; Key = $entry.Key; Name = $entry.Name
            OldPolicy = $(if ($null -ne $old) {
                [pscustomobject]@{ Data = $old.Data; Type = $old.Type.ToString() }
            } else { $null })
            RegistryPath = $entry.RegistryPath
            RegistryBefore = Get-RegistryValueBefore $entry.RegistryPath $entry.Name
        }
    }
)
$PreferenceBefore = @(
    foreach ($entry in $Preferences) {
        [pscustomobject]@{
            Path = $entry.Path; Name = $entry.Name
            Before = Get-RegistryValueBefore $entry.Path $entry.Name
        }
    }
)
$ServiceBefore = @(
    if ($ServiceNames.Count -gt 0) {
        $existingServices = @(Get-Service)
        foreach ($name in $ServiceNames) {
            $service = $existingServices | Where-Object Name -EQ $name
            if ($null -eq $service) {
                Write-Host "Service not found; skipped: $name"
                continue
            }
            [pscustomobject]@{
                Name = $name; StartType = $service.StartType.ToString()
                WasRunning = ($service.Status -eq 'Running')
                DelayedAutoStart = Get-RegistryValueBefore `
                    "HKLM:\SYSTEM\CurrentControlSet\Services\$name" 'DelayedAutoStart'
            }
        }
    }
)
$TaskBefore = @(
    if ($TaskNames.Count -gt 0) {
        $existingTasks = @(Get-ScheduledTask)
        foreach ($name in ($TaskNames | Sort-Object -Unique)) {
            $task = $existingTasks | Where-Object { ($_.TaskPath + $_.TaskName) -eq $name }
            if ($null -eq $task) {
                Write-Host "Task not found; skipped: $name"
                continue
            }
            [pscustomobject]@{
                TaskPath = $task.TaskPath; TaskName = $task.TaskName
                WasEnabled = ($task.State -ne 'Disabled')
            }
        }
    }
)
[pscustomobject]@{
    ComputerName = $env:COMPUTERNAME
    UserSid = [System.Security.Principal.WindowsIdentity]::GetCurrent().User.Value
    Policies = $PolicyBefore; Preferences = $PreferenceBefore
    Services = $ServiceBefore; Tasks = $TaskBefore
    Features = $FeatureBefore; Packages = $Packages
    ProvisionedPackages = $ProvisionedPackages
} | Export-Clixml -Path "$BackupDirectory\state.xml" -Depth 10
Write-Host "Backup directory: $BackupDirectory" -ForegroundColor Cyan

$script:FailureCount = 0
function Invoke-Change {
    param([string]$Label, [scriptblock]$Action)
    try {
        & $Action
        Write-Host "Applied: $Label"
    } catch {
        $script:FailureCount++
        Write-Warning ("Failed: {0}: {1}" -f $Label, $_.Exception.Message)
    }
}

New-Item -ItemType Directory -Force -Path `
    (Split-Path $MachinePol), (Split-Path $UserPol) | Out-Null
foreach ($entry in $Policies) {
    Invoke-Change "$($entry.Key)\$($entry.Name)" {
        Set-PolicyFileEntry -Path $entry.Path -Key $entry.Key `
            -ValueName $entry.Name -Data $entry.Data -Type DWord
    }
}
foreach ($entry in $Preferences) {
    Invoke-Change "$($entry.Path)\$($entry.Name)" {
        if (-not (Test-Path -LiteralPath $entry.Path)) {
            New-Item -Path $entry.Path -Force | Out-Null
        }
        New-ItemProperty -LiteralPath $entry.Path -Name $entry.Name `
            -Value $entry.Data -PropertyType DWord -Force | Out-Null
    }
}
foreach ($entry in $ServiceBefore) {
    Invoke-Change "Disable service $($entry.Name)" {
        # Do not force-stop dependent services that have not been backed up.
        Stop-Service -Name $entry.Name
        Set-Service -Name $entry.Name -StartupType Disabled
        $actual = Get-Service -Name $entry.Name
        if ($actual.Status -ne 'Stopped' -or $actual.StartType -ne 'Disabled') {
            throw "Actual state: $($actual.Status) / $($actual.StartType)"
        }
    }
}
foreach ($entry in $TaskBefore) {
    Invoke-Change "Disable task $($entry.TaskPath)$($entry.TaskName)" {
        Disable-ScheduledTask -TaskPath $entry.TaskPath -TaskName $entry.TaskName | Out-Null
        $actual = Get-ScheduledTask -TaskPath $entry.TaskPath -TaskName $entry.TaskName
        if ($actual.State -ne 'Disabled') { throw "Actual state: $($actual.State)" }
    }
}

Invoke-Change 'Refresh local policy' {
    & gpupdate.exe /force /wait:-1
    if ($LASTEXITCODE -ne 0) { throw "gpupdate exit code: $LASTEXITCODE" }
}
Write-Host "Backup directory: $BackupDirectory" -ForegroundColor Cyan
Write-Host 'Restart Windows, then verify effective settings and component states.'
if ($script:FailureCount -gt 0) {
    throw "$($script:FailureCount) operation(s) failed; review the warnings above."
}

只应用上表中的默认配置：

powershell.exe -ExecutionPolicy Bypass -File "$HOME\Desktop\disable-telemetry.ps1"

需要额外关闭的项目通过参数选择：

参数 增加的操作与影响
-Compatibility 关闭 AIT、Inventory、Steps Recorder、Program Compatibility Assistant 和 CEIP；会失去对应的兼容性辅助功能
-Location 关闭定位、Windows 定位提供程序及定位脚本；应用将无法使用这些定位能力
-Services 停止并禁用下表中的 6 个服务；包含诊断、兼容性和设备管理相关功能
-Tasks 禁用下表中的 13 个计划任务；包含兼容性评估、反馈、磁盘诊断及地图更新
-LegacyAnalytics 写入旧 Desktop Analytics / 商业数据管道策略，并设 LimitEnhancedDiagnosticDataWindowsAnalytics=1；仅用于对应旧环境

例如，需要同时关闭兼容性收集、这些服务和任务时，使用：

powershell.exe -ExecutionPolicy Bypass -File "$HOME\Desktop\disable-telemetry.ps1" -Compatibility -Services -Tasks

-Services 的具体范围：

服务 功能
DiagTrack Connected User Experiences and Telemetry
whesvc Windows Health and Optimized Experiences
InventorySvc 清单与兼容性评估
diagsvc Diagnostic Execution Service
PcaSvc Program Compatibility Assistant
dmwappushservice WAP Push 消息路由，涉及部分设备管理场景

-Tasks 的具体范围，路径均在 \Microsoft\Windows\ 下：

目录 任务
Application Experience Microsoft Compatibility Appraiser、MareBackup、PcaPatchDbTask、SdbinstMergeDbTask、StartupAppTask
Autochk Proxy
Customer Experience Improvement Program Consolidator、UsbCeip
DiskDiagnostic Microsoft-Windows-DiskDiagnosticDataCollector
Feedback\Siuf DmClient、DmClientOnScenarioDownload
Maps MapsToastTask、MapsUpdateTask

不存在的服务和任务会报告后跳过；写入或禁用失败会输出具体错误，脚本最终返回失败。成功写入策略只表示配置已保存，重启后还要核对实际行为。启用相应参数时，服务预期为 Stopped / Disabled，任务预期为 Disabled。

旧 AllowDesktopAnalyticsProcessing / AllowCommercialDataPipeline 已弃用，在新版 Windows 上不提供额外的遥测关闭效果。LimitEnhancedDiagnosticDataWindowsAnalytics=1 是在可选诊断级别下限制 Desktop Analytics 数据，不能单独当作关闭诊断数据的开关。

基础：应用兼容性策略、旧 Analytics 策略范围。

关闭 Windows 其他组件

默认关闭 Recall 快照和组件启用、搜索联网与云端搜索相关策略，关闭 Delivery Optimization 的 peer 传输，并卸载当前用户的 Microsoft.Copilot。以下组件操作不依赖先关闭 Defender。

先查看本机实际存在的功能与包：

Get-WindowsOptionalFeature -Online | Where-Object FeatureName -EQ Recall
Get-AppxPackage -AllUsers | Where-Object Name -Match 'Copilot|Recall|AIX' |
  Select-Object Name, PackageFullName
Get-AppxProvisionedPackage -Online | Where-Object DisplayName -Match 'Copilot|Recall|AIX' |
  Select-Object DisplayName, PackageName
Get-Service WSearch, SysMain, DoSvc, WSAIFabricSvc -ErrorAction SilentlyContinue

Recall、Copilot 与搜索策略

范围 默认操作
Recall 快照 机器和用户 DisableAIDataAnalysis=1
Recall 组件 机器 AllowRecallEnablement=0；在支持该策略的系统上移除组件及已有快照，需要重启
Copilot 应用 卸载当前用户的 Microsoft.Copilot，不自动处理其他用户或新用户模板
搜索联网结果 DisableWebSearch=1、ConnectedSearchUseWeb=0
云端与位置搜索 AllowCloudSearch=0、AllowSearchToUseLocation=0，旧 Cortana 环境另设 AllowCortana=0
资源管理器搜索历史 用户 DisableSearchBoxSuggestions=1，关闭历史查询建议和保存
Delivery Optimization DODownloadMode=0，使用 HTTP 下载，不与 peer 共享

DisableSearchBoxSuggestions 是用户策略，官方定义针对资源管理器历史建议，不能把它单独等同于关闭开始菜单 Bing 搜索。联网搜索策略也有 Edition 限制，例如 ConnectedSearchUseWeb 的官方映射不覆盖 Pro；Home / Pro 上不能只凭注册表值判断联网搜索已关闭。保留本地索引时，不需要禁用 WSearch。

Recall 的策略以当前 Windows AI 文档中的 DisableAIDataAnalysis 和 AllowRecallEnablement 为准；不写入缺少当前文档依据的 TurnOffSavedSnapshots。AllowRecallEnablement 需要 Windows 11 24H2 的对应更新及支持的设备。关闭组件会删除已有快照，恢复配置不能找回它们。

当前 Copilot 是独立应用，旧 TurnOffWindowsCopilot 已弃用，不能代替应用卸载或阻止新版应用安装。脚本仅在显式加 -LegacyCopilot 时写入这条用户策略。若需要持续阻止新版应用安装，可使用微软文档中的 AppLocker 应用规则。

基础：Recall 管理、Windows AI 策略、Copilot 应用移除与安装控制、搜索策略、资源管理器搜索历史。

完整脚本与可选组件

将以下代码保存为 ~/Desktop/disable-residual.ps1。默认的精确包名在顶部 $AppxNames 数组中；需要处理其他应用时先核对实际 Name，再修改数组，不使用 Microsoft.Windows.Ai* 等大范围通配符。

#Requires -Version 5.1
#Requires -RunAsAdministrator
[CmdletBinding()]
param(
    [string[]]$AppxNames = @('Microsoft.Copilot'),
    [switch]$AllUsers,
    [switch]$RemoveProvisioned,
    [switch]$RemoveRecall,
    [switch]$DisableAIFabric,
    [switch]$DisableMdm,
    [switch]$DisableSysMain,
    [switch]$DisableSearchIndex,
    [switch]$DisableDeliveryService,
    [switch]$LegacyCopilot
)

        [System.Management.Automation.WildcardPattern]::ContainsWildcardCharacters($name)) {

额外操作通过参数选择：

参数 增加的操作与影响
-AllUsers 按精确包名卸载所有现有用户的应用；默认只卸载当前用户
-RemoveProvisioned 移除同名 provisioned 模板包，使新建用户不再从该模板获得应用；不代替现有用户卸载
-RemoveRecall 本机存在已启用的 Recall 可选功能时，另用 DISM 关闭；无此功能则跳过
-DisableAIFabric 停止并禁用 WSAIFabricSvc，确认服务停用后再结束 WorkloadsSessionHost / WorkloadsSessionManager；依赖该服务的本地 AI 功能会受影响
-DisableMdm 设置 AutoEnrollMDM=0、DisableRegistration=1，禁用 EnterpriseMgmt、Management、Workplace Join 下现有任务，包含嵌套目录
-DisableSysMain 停止并禁用 SysMain；按实际性能问题选择，NVMe 本身不是判断依据
-DisableSearchIndex 停止并禁用 WSearch，影响开始菜单、文件及部分 Outlook 搜索
-DisableDeliveryService 停止并禁用 DoSvc，可能影响 Windows Update / Store 下载；只关 P2P 时不需要此参数
-LegacyCopilot 为使用旧 Copilot 侧栏的环境写入 TurnOffWindowsCopilot=1 用户策略

例如，同时处理所有现有用户和新用户模板，并关闭本地搜索索引：

powershell.exe -ExecutionPolicy Bypass -File "$HOME\Desktop\disable-residual.ps1" -AllUsers -RemoveProvisioned -DisableSearchIndex

MDM 参数用于明确不再需要设备注册、预配和工作账户加入任务的机器。它不等于退出已经注册的 Intune / Entra，也不适合直接用于仍由组织管理的设备；可先用 dsregcmd /status 查看加入状态。

DODownloadMode=0 已足以关闭 peer 传输，DoSvc 可以继续提供 HTTP 下载。DOMaxBackgroundDownloadBandwidth=0 / DOMaxForegroundDownloadBandwidth=0 表示动态调整，不表示“禁止下载”，因此不把它们加入关闭脚本。

预期：所选包不再出现在对应用户或模板的查询结果中，Recall 状态在重启后符合所选策略；显式停用的服务为 Stopped / Disabled，MDM 任务为 Disabled。进程被结束、包卸载成功或策略值存在，都不能证明以后不会被更新重新启用。

基础：MDM 自动注册、Delivery Optimization 模式与带宽。

恢复遥测与其他组件

将以下代码保存为 ~/Desktop/restore-windows-components.ps1，在原机器上以原账户提权运行。它只恢复备份中列出的项；原有本地策略写回原值，原先不存在的项才删除，保留其他本地策略及原先直接写入的注册表设置。

restore-windows-components.ps1：按修改前记录恢复策略、偏好、服务、任务及 Recall 
#Requires -Version 5.1
#Requires -RunAsAdministrator
[CmdletBinding()]
param(
    [Parameter(Mandatory)]
    [string]$BackupDirectory
)

$ErrorActionPreference = 'Stop'
Import-Module PolicyFileEditor
$state = Import-Clixml -LiteralPath (Join-Path $BackupDirectory 'state.xml')
$sid = [System.Security.Principal.WindowsIdentity]::GetCurrent().User.Value
if ($state.ComputerName -ne $env:COMPUTERNAME -or $state.UserSid -ne $sid) {
    throw 'Run the restore on the original computer, elevated as the original user.'
}

$script:FailureCount = 0
function Invoke-Restore {
    param([string]$Label, [scriptblock]$Action)
    try {
        & $Action
        Write-Host "Restored: $Label"
    } catch {
        $script:FailureCount++
        Write-Warning ("Failed: {0}: {1}" -f $Label, $_.Exception.Message)
    }
}

function Restore-RegistryValue {
    param([string]$Path, [string]$Name, $Before)
    if ($Before.Exists) {
        if (-not (Test-Path -LiteralPath $Path)) {
            New-Item -Path $Path -Force | Out-Null
        }
        New-ItemProperty -LiteralPath $Path -Name $Name -Value $Before.Data `
            -PropertyType $Before.Type -Force | Out-Null
    } elseif (Test-Path -LiteralPath $Path) {
        $key = Get-Item -LiteralPath $Path
        if ($key.GetValueNames() -contains $Name) {
            Remove-ItemProperty -LiteralPath $Path -Name $Name
        }
    }
}

# Touch only the entries listed in this run's snapshot.
foreach ($entry in $state.Policies) {
    Invoke-Restore "$($entry.Key)\$($entry.Name)" {
        if ($null -ne $entry.OldPolicy) {
            New-Item -ItemType Directory -Force -Path (Split-Path $entry.Path) | Out-Null
            Set-PolicyFileEntry -Path $entry.Path -Key $entry.Key -ValueName $entry.Name `
                -Data $entry.OldPolicy.Data -Type $entry.OldPolicy.Type
        } elseif (Test-Path -LiteralPath $entry.Path) {
            Remove-PolicyFileEntry -Path $entry.Path -Key $entry.Key -ValueName $entry.Name
        }
    }
}
Invoke-Restore 'Refresh local policy' {
    & gpupdate.exe /force /wait:-1
    if ($LASTEXITCODE -ne 0) { throw "gpupdate exit code: $LASTEXITCODE" }
}
foreach ($entry in $state.Policies) {
    # Preserve pre-existing direct registry settings when there was no local
    # policy entry. Existing policy entries are reapplied by gpupdate above.
    if ($null -eq $entry.OldPolicy) {
        Invoke-Restore "$($entry.RegistryPath)\$($entry.Name)" {
            Restore-RegistryValue $entry.RegistryPath $entry.Name $entry.RegistryBefore
        }
    }
}
foreach ($entry in $state.Preferences) {
    Invoke-Restore "$($entry.Path)\$($entry.Name)" {
        Restore-RegistryValue $entry.Path $entry.Name $entry.Before
    }
}
foreach ($entry in $state.Services) {
    Invoke-Restore "Service $($entry.Name)" {
        # A service can originally be running with its startup type disabled.
        if ($entry.WasRunning -and $entry.StartType -eq 'Disabled') {
            Set-Service -Name $entry.Name -StartupType Manual
            try {
                Start-Service -Name $entry.Name
            } finally {
                Set-Service -Name $entry.Name -StartupType Disabled
            }
        } else {
            Set-Service -Name $entry.Name -StartupType $entry.StartType
            if ($entry.WasRunning) {
                Start-Service -Name $entry.Name
            } else {
                Stop-Service -Name $entry.Name
            }
        }
        Restore-RegistryValue "HKLM:\SYSTEM\CurrentControlSet\Services\$($entry.Name)" `
            'DelayedAutoStart' $entry.DelayedAutoStart
    }
}
foreach ($entry in $state.Tasks) {
    Invoke-Restore "Task $($entry.TaskPath)$($entry.TaskName)" {
        if ($entry.WasEnabled) {
            Enable-ScheduledTask -TaskPath $entry.TaskPath -TaskName $entry.TaskName | Out-Null
        } else {
            Disable-ScheduledTask -TaskPath $entry.TaskPath -TaskName $entry.TaskName | Out-Null
        }
    }
}
foreach ($entry in $state.Features) {
    Invoke-Restore "Optional feature $($entry.Name)" {
        $actual = Get-WindowsOptionalFeature -Online -FeatureName $entry.Name
        if ($actual.State -in @('EnablePending', 'DisablePending')) {
            throw 'A feature change is pending; restart Windows, then retry the restore.'
        }
        if ($entry.State -eq 'Enabled') {
            Enable-WindowsOptionalFeature -Online -FeatureName $entry.Name -NoRestart | Out-Null
        }
    }
}

if ($state.Packages.Count -gt 0 -or $state.ProvisionedPackages.Count -gt 0) {
    Write-Warning 'AppX applications and provisioned packages need their Store or installation source.'
    $state.Packages | Select-Object -Property @('Name', 'PackageFullName', 'AllUsers') | Format-Table
    $state.ProvisionedPackages | Select-Object -Property @('DisplayName', 'PackageName') | Format-Table
}
Write-Host 'Restart Windows and verify the restored settings.'
if ($script:FailureCount -gt 0) {
    throw "$($script:FailureCount) restore operation(s) failed; review the warnings above."
}
powershell.exe -ExecutionPolicy Bypass -File "$HOME\Desktop\restore-windows-components.ps1" -BackupDirectory $BackupDirectory

多次执行产生了多份备份时，按时间从新到旧恢复，直到所需的基线。恢复 Recall 可选功能可能需要 Windows Update 或安装源；若功能状态仍为 Pending，先重启再重试。恢复服务后，之前终止的 AI 进程由服务或重新登录、重启重新启动。

应用包信息用于确认重装范围，恢复脚本不会凭包名自动找回安装文件。已卸载的 AppX 应用需从 Store 或原安装源重装；新用户模板需用原包及依赖执行 Add-AppxProvisionedPackage。Recall 已删除的快照无法恢复。

Defender 使用其章节中的独立备份，按该节逐项还原偏好、任务、防火墙和本地策略；不使用这里的 state.xml。无论哪种恢复，都不删除整个 Registry.pol。

单独恢复 Defender 的某个本地策略时，先查备份中的原值。下面以 DisableAntiSpyware 为例；其他项替换 $Key 和 $Name，逐项处理：

$DefenderBackup = 'C:\Users\<用户名>\defender-before-<时间戳>'
$MachinePol = "$env:SystemRoot\System32\GroupPolicy\Machine\Registry.pol"
$Key = 'SOFTWARE\Policies\Microsoft\Windows Defender'
$Name = 'DisableAntiSpyware'
$OriginalFile = Join-Path $DefenderBackup 'Machine-Registry.pol'
$Original = if (Test-Path $OriginalFile) {
  Get-PolicyFileEntry -Path $OriginalFile -Key $Key -ValueName $Name
} else { $null }
if ($null -ne $Original) {
  Set-PolicyFileEntry -Path $MachinePol -Key $Key -ValueName $Name -Data $Original.Data -Type $Original.Type
} elseif (Test-Path $MachinePol) {
  Remove-PolicyFileEntry -Path $MachinePol -Key $Key -ValueName $Name
}
gpupdate /force
