Mac Pro 2013 的 4K SST 右侧闪烁

结论：将 Mavericks 显示初始化的 DISPCLK 请求从 ROM 默认的 500 MHz 提高至 600 MHz 后，一次重启对照中右侧闪烁消失，物理输出仍为 4K60。这支持显示时钟裕量不足的假设；活动 DISPCLK 未直接测量，也未完成恢复原版的 A/B/A 对照。

适用范围仅为 MacPro6,1 双 D500 + OS X 10.9.5 13F1911。本文提供完整构建、部署与验证脚本：从目标机自己的原版驱动生成补丁，不需要作者的实验项目或采集目录。其他显卡、系统构建或二进制身份不匹配时停止。

symptom

Mac Pro 2013 双 D500 在 Mavericks 下输出 4K60 时，屏幕右侧约一英寸宽的区域持续闪烁、重影或撕裂，其余画面正常。

显示器通过 mini DisplayPort 直连，使用 SST（Single-Stream Transport，单流传输）传送整幅画面。

项目 实测环境
机器 MacPro6,1，双 FirePro D500，PCI 1002:679e，每卡 3 GB
系统 OS X 10.9.5 / 13F1911，内核 xnu-2422.115.15~1
驱动 AMD 1.24.39，bundle version 1.2.4
显示器 NE173QUM_NY1
输出 3840×2160，60 Hz，像素时钟 533.28 MHz

系统显示的“1080p”是 HiDPI 逻辑桌面尺寸，物理输出仍为 3840×2160。

evidence

display pipeline

显示路径可以简化为：

flowchart LR
    A[帧缓冲中的图像] --> B[显示引擎取数与处理]
    B --> C[按显示时序扫描输出]
    C --> D[DisplayPort 编码与传输]
    D --> E[显示器面板]

显示器已经能够接收 4K60，排查重点是各阶段能否持续跟上输出时序。内部显示引擎负责取数和处理，DP 链路负责传输，两者有各自的时钟要求。

本机加载了 AMD7000Controller、AMDFramebuffer、AMDSupport 和 AMDTahitiGraphicsAccelerator，D500 的 framebuffer personality 为 ATY,Kani/KaniS。对比这些组件的 Mavericks 与 Yosemite 版本，可以追踪显示初始化和时钟管理的变化。

pixel clock

可见像素的更新量为：

3840 × 2160 × 60 = 497,664,000 像素/秒

加上行、场消隐，本次模式每帧共有 8,888,000 个时序像素：

像素时钟 = 8,888,000 × 60 = 533,280,000 Hz = 533.28 MHz

排查涉及三个量：

名称 作用 本次数据
像素时钟 决定显示扫描时序 533.28 MHz
DISPCLK 驱动 GPU 内部显示引擎 ROM 默认值 500 MHz；补丁请求值 600 MHz
DP 链路速率 决定通道传输能力 修复后为 4 lanes，每 lane 5.40 Gbps

DISPCLK 对像素时钟的需求取决于缩放、像素处理方式和流水线。500 MHz 的默认值低于本模式的 533.28 MHz 像素时钟，因此需要检查它是否为显示引擎留出了足够裕量。

rom default

两张 D500 的 ATOM ROM 中，FirmwareInfo v2.2 的 +0x28 字段均为 50000，对应 ulDefaultDispEngineClkFreq。字段定义给出的单位是 10 kHz：

50000 × 10 kHz = 500 MHz

反汇编确认了这条调用路径：

  1. AMDSupport 的 AtiAtomBiosSharedServices::getDefaultDisplayEngineClock() 读取该字段。
  2. AMD7000Controller::hwInitializeDCLK() 在缓存时钟为零时，通过 AtomBiosProxy::getDefaultDisplayEngineClock() 取得默认值并写入缓存。
  3. 随后调用 hwProgramDcPixelClock()，沿 BIOS 接口请求设置显示引擎时钟。

旧初始化路径使用 ROM 的 500 MHz 默认值。实验将提高这个请求值，检验显示时钟裕量不足的假设。

yosemite comparison

用于对比的三个版本：

系统 Build AMD 驱动 来源
Mavericks 10.9.5 13F1911 1.24.39 D500 真机导出
Yosemite 10.10.2 14C109 1.30.5 Apple Combo Update
Yosemite 10.10.3 14D136 1.32.20 Apple Combo Update

更新包只用来提取二进制对照。

两个 Yosemite 版本都增加了 SIDisplayEngineClock，由控制器初始化路径创建。它根据显示模式计算时钟，考虑缩放、颜色条件和裕量系数。

其静态 MaxClocksByState 表中，state 3 的显示时钟为 600000 kHz，即 600 MHz。初始化时还会按 GPU revision 改表：getActualRevisionId() < 0x14 时，该项改为 500000 kHz。对 D500 设备 0x679e 的静态分析显示，它也会进入这个分支。

Yosemite 在初始化后还会按显示模式计算和设置时钟。本实验参考静态表选取 600 MHz，检验提高 Mavericks 初始化请求值的效果。

interpretation

后续真机对照中，只将默认时钟 getter 的返回值改为 600 MHz 请求值，右侧异常便消失，物理输出保持 4K60。这支持“旧初始化值在该模式下缺少显示时钟裕量”的判断。具体发生欠载的硬件环节仍待定位。

reproduction

clock request

保留 Mavericks 驱动，在 hwInitializeDCLK() 读取 BIOS 默认值的位置返回 60000（10 kHz 单位）。后续缓存写入和 BIOS 编程沿用原逻辑。

核心改动的伪代码：

- clock_10khz = bios.getDefaultDisplayEngineClock();
+ clock_10khz = 60000;

保留旧驱动是为了兼容原系统接口。例如控制器虚表的 0xcc8 槽位，在 Mavericks 中是 regw32，在 10.10.2 中却是 regw16；直接搬入新函数机器码可能调用错误的方法。

relocation

修改位置是一条等待外部重定位的 CALL：

项目 原版 补丁版
指令地址 0x27d84，由 Mach-O 段信息映射到文件位置 相同
指令字节 E8 00 00 00 00 B8 60 EA 00 00
行为 调用默认时钟 getter mov eax, 60000
对应重定位 X86_64_RELOC_BRANCH 删除
外部重定位总数 5212 5211

原指令后四字节保存调用位移，由链接器填入；新指令同一位置保存立即数 60000。必须删除原重定位，否则链接器会覆盖时钟值。

构建工具压紧重定位表、更新记录数，保留其余记录的顺序和内容，并更换 Mach-O UUID 以识别补丁版。文件长度不变，共改变 2119 个字节位置。

build

在目标 Mavericks 的终端执行。先准备工作目录，再将文末 tools 中三个完整脚本分别保存到该目录，文件名保持一致。脚本兼容系统自带的 Python 2.7，不需要安装 Python 3。

mkdir -p "$HOME/d500-dispclk600"
cd "$HOME/d500-dispclk600"

先核对系统、双 D500、磁盘原件、启动缓存和已加载 UUID：

sudo /usr/bin/python -B manage-dispclk600.py verify --expect original

预期：UUID 为 5dd5f117-8f64-3b72-9e71-9f20af1c76ae，started、prelinked 均为 true。任何身份或缓存检查失败都停止，不修改偏移、摘要或 UUID 来绕过检查。

复制本机原版 bundle，离线构建：

ditto --rsrc --extattr --acl \
  /System/Library/Extensions/AMD7000Controller.kext original.kext
/usr/bin/python -B dispclk600.py \
  --source original.kext/Contents/MacOS/AMD7000Controller \
  --output output

output 必须尚不存在。预期生成 output/AMD7000Controller 和 output/report.json，报告状态为 built-not-installed；源文件不变。构建器核对源 SHA-256、Mach-O 结构、原指令、重定位目标和成品 SHA-256，输出应与文末 binary identity 一致。

install

安装前保留可启动的恢复环境，并确认能在恢复终端访问 Mavericks 系统卷。安装命令只适用于已通过上一节检查、且存在相同右侧闪烁问题的机器。

sudo /usr/bin/python -B manage-dispclk600.py install \
  --candidate "$PWD/output/AMD7000Controller"

脚本在新建的 /var/db/d500-dispclk600/ 中保存完整原 bundle、全部 kext 缓存、目录时间和日志，先运行 Mavericks 原生 kextutil -no-load 预检，再替换控制器可执行文件。已有事务目录时拒绝覆盖，不要删除唯一备份重跑。

随后依次执行目标系统自己的 kextcache -system-prelinked-kernel 和 kextcache -system-caches，解压启动缓存、核对 Adler-32、内嵌控制器 UUID、bundle 路径与组件清单。原缓存中的组件必须保留；仅允许历史实验中出现的原生 msdosfs 1.9 增项，其他清单变化会失败。替换后的构建或检查失败时自动恢复原文件与缓存；若进程被强制终止或恢复也失败，按 rollback 操作。

预期末行含 Ready for a manual reboot。它表示磁盘和启动缓存已通过检查，当前运行的驱动仍是原版。脚本不重启、不热卸载或热加载显卡驱动。

verify

保存工作并正常重启后，回到工作目录：

cd "$HOME/d500-dispclk600"
sudo /usr/bin/python -B manage-dispclk600.py verify --expect patched
system_profiler SPDisplaysDataType
ioreg -l -w 0 -r -c IOFramebuffer > after-framebuffers.txt

预期：磁盘文件和启动缓存匹配补丁身份，内核查询返回 UUID 39e1d05a-4681-55b2-affb-f495f92edf3e，started、prelinked 均为 true。

实际画面仍需单独验收：

  • 在显示器输入信息中确认 3840×2160、60 Hz；若可读取物理时序，本次参考值为像素时钟 533.28 MHz、每帧 8,888,000 个时序像素。system_profiler 仅显示逻辑“1080p”不能证明物理输出降级或保持 4K60。
  • 在相同分辨率、刷新率、线材与显示器设置下，检查右侧区域在静态画面、窗口拖动和视频播放时是否仍闪烁、重影或撕裂。记录结果；加载成功本身不证明问题已解决。
  • 如需加强因果判断，保留补丁版结果，再按下一节恢复原版、正常重启，以相同条件检查症状是否回来。原实验尚未完成这个 A/B/A 对照。

右侧异常 持续可见 消失，目视反馈“非常正常”

内核查询确认补丁 UUID 已加载，OSBundleStarted、OSBundlePrelinked 均为 true。图形组件的 63 条采集记录中，仅 AMD7000Controller 可执行文件改变，其余 62 条保持一致；kext 缓存按部署流程重新生成。

signature

补丁使原 Apple 签名失效，缓存构建记录 WARNING - Invalid signature。位于 /System/Library/Extensions 的候选仍进入预链接缓存，并在重启后加载。本实验沿用系统原有签名策略。

Mavericks 的 kextutil 诊断代码分别处理签名和可加载性。加载分支会拒绝 /Library/Extensions 中的无效签名及证书吊销，部署路径须与本次实验一致。

rollback

以下回退以安装后未更新系统或变更其他 kext 为前提。系统仍可启动时，在同一工作目录恢复：

sudo /usr/bin/python -B manage-dispclk600.py rollback

预期：原文件及原启动缓存的摘要、UUID 均通过检查，输出 Original file and caches restored。脚本保留恢复前的缓存为 /System/Library/Caches/com.apple.kext.caches.dispclk600-displaced，不合并两套缓存。正常重启后核对：

cd "$HOME/d500-dispclk600"
sudo /usr/bin/python -B manage-dispclk600.py verify --expect original

无法启动图形系统时，从恢复环境打开终端，将 target_volume 改为实际挂载的 Mavericks 系统卷。下面只恢复该卷自己的原 bundle 和缓存，不使用恢复系统的 kextcache 重建目标系统缓存：

(
  set -eu
  target_volume='/Volumes/Mavericks'
  backup_dir="$target_volume/private/var/db/d500-dispclk600"
  cache_dir="$target_volume/System/Library/Caches/com.apple.kext.caches"
  test "$(/usr/libexec/PlistBuddy -c 'Print :ProductBuildVersion' \
    "$target_volume/System/Library/CoreServices/SystemVersion.plist")" = '13F1911'
  test "$(shasum -a 256 \
    "$backup_dir/original.kext/Contents/MacOS/AMD7000Controller" \
    | awk '{print $1}')" = \
    '41f2200d2c3eb614af971235fd860355b8de2473214fe829e99039fedcc2aa82'
  test -f "$backup_dir/backup.json"
  test -f "$backup_dir/caches/Startup/kernelcache"
  (cd "$backup_dir" && shasum -a 256 -c SHA256SUMS)
  test ! -e "$cache_dir.dispclk600-recovery"
  ditto --rsrc --extattr --acl "$backup_dir/original.kext" \
    "$target_volume/System/Library/Extensions/AMD7000Controller.kext"
  if test -d "$cache_dir"; then
    mv "$cache_dir" "$cache_dir.dispclk600-recovery"
  fi
  ditto --rsrc --extattr --acl "$backup_dir/caches" "$cache_dir"
  sync
)

命令成功后从 Mavericks 卷正常启动，再执行 verify --expect original。如缺少完整备份或系统卷身份不符，停止恢复，不混用其他机器、系统构建的驱动或缓存。

tools

将三个代码块分别保存为 dispclk600.py、kernelcache.py 和 manage-dispclk600.py，放在 $HOME/d500-dispclk600/ 中。它们只依赖 Python 标准库与 Mavericks 自带工具；不包含或分发 Apple 驱动二进制。

dispclk600.py：核对原版并离线生成补丁 
"""Build the fixed D500 / 13F1911 controller from an original file; never install."""

from __future__ import print_function

import argparse
import binascii
import hashlib
import json
import os
import struct
import uuid


SOURCE_SHA256 = "41f2200d2c3eb614af971235fd860355b8de2473214fe829e99039fedcc2aa82"
EXPECTED_OUTPUT_SHA256 = "fbe104660895d00f4f42ba633a3b3006f78795eeabbb07d9d95b3eb5383d45ee"
CALL_ADDRESS = 0x27D84
CALLEE = "__ZN13AtomBiosProxy28getDefaultDisplayEngineClockEv"
CLOCK_10KHZ = 60000
PROBE_UUID = uuid.uuid5(uuid.NAMESPACE_URL, "osx109/sst/dispclk600/v1/" + SOURCE_SHA256)


def unpack(data, layout, offset):
    if offset < 0 or offset + struct.calcsize(layout) > len(data):
        raise ValueError("Mach-O structure is outside the file")
    return struct.unpack_from(layout, data, offset)


def image_layout(data):
    header = unpack(data, "<8I", 0)
    if header[0] != 0xFEEDFACF or header[1] != 0x01000007 or header[3] != 11:
        raise ValueError("Expected a thin x86_64 MH_KEXT_BUNDLE")
    commands_end = 32 + header[5]
    if commands_end > len(data) or header[4] > header[5] // 8:
        raise ValueError("Invalid Mach-O load-command region")
    cursor = 32
    segments = []
    tables = {}
    for _ in range(header[4]):
        command, size = unpack(data, "<II", cursor)
        if size < 8 or size % 8 or cursor + size > commands_end:
            raise ValueError("Invalid Mach-O load-command size")
        if command == 0x19:
            if size < 72:
                raise ValueError("Truncated segment command")
            segment = unpack(data, "<II16sQQQQiiII", cursor)
            if segment[5] + segment[6] > len(data):
                raise ValueError("Segment is outside the file")
            segments.append((segment[3], segment[5], segment[6]))
        elif command in (2, 11, 0x1B):
            required = {2: 24, 11: 80, 0x1B: 24}[command]
            if size != required or command in tables:
                raise ValueError("Invalid or duplicate symbol/UUID command")
            tables[command] = cursor
        cursor += size
    if cursor != commands_end or set(tables) != {2, 11, 0x1B}:
        raise ValueError("Missing or inconsistent Mach-O metadata")
    symtab = unpack(data, "<6I", tables[2])
    dysymtab = unpack(data, "<20I", tables[11])
    if (symtab[2] + symtab[3] * 16 > len(data)
            or symtab[4] + symtab[5] > len(data)
            or dysymtab[16] + dysymtab[17] * 8 > len(data)):
        raise ValueError("Mach-O symbol or relocation table is truncated")
    names = []
    strings_end = symtab[4] + symtab[5]
    for index in range(symtab[3]):
        string_index = unpack(data, "<I", symtab[2] + index * 16)[0]
        if string_index >= symtab[5]:
            raise ValueError("Invalid Mach-O string index")
        start = symtab[4] + string_index
        end = data.find(b"\0", start, strings_end)
        if end < 0:
            raise ValueError("Unterminated Mach-O symbol")
        names.append(data[start:end].decode("utf-8"))
    relocations = []
    for index in range(dysymtab[17]):
        start = dysymtab[16] + index * 8
        address, flags = unpack(data, "<iI", start)
        external = bool(flags & (1 << 27))
        symbol_index = flags & 0xFFFFFF
        if external and symbol_index >= len(names):
            raise ValueError("Invalid external relocation symbol")
        relocations.append({
            "address": address, "flags": flags, "external": external,
            "symbol": names[symbol_index] if external else None,
            "raw": data[start:start + 8],
        })
    return {
        "segments": segments, "relocations": relocations,
        "relocation_offset": dysymtab[16],
        "relocation_count_offset": tables[11] + 17 * 4,
        "uuid_offset": tables[0x1B] + 8,
    }


def replace_clock_call(data, call_address, callee, marker):
    image = image_layout(data)
    offsets = [file_offset + call_address - address
               for address, file_offset, length in image["segments"]
               if address <= call_address and call_address + 5 <= address + length]
    if len(offsets) != 1:
        raise ValueError("Clock call is not in exactly one file-backed segment")
    code_offset = offsets[0]
    if data[code_offset:code_offset + 5] != b"\xe8\0\0\0\0":
        raise ValueError("Expected an unrelocated five-byte CALL")
    matches = [index for index, relocation in enumerate(image["relocations"])
               if relocation["address"] == call_address + 1]
    if len(matches) != 1:
        raise ValueError("Expected exactly one relocation for the clock call")
    index = matches[0]
    relocation = image["relocations"][index]
    if (relocation["symbol"] != callee or not relocation["external"]
            or relocation["flags"] >> 24 != 0x2D):
        raise ValueError("Clock call has the wrong symbol or relocation type")
    result = bytearray(data)
    result[code_offset:code_offset + 5] = b"\xb8" + struct.pack("<I", CLOCK_10KHZ)
    remaining = image["relocations"][:index] + image["relocations"][index + 1:]
    table = b"".join(record["raw"] for record in remaining) + b"\0" * 8
    start = image["relocation_offset"]
    result[start:start + len(table)] = table
    struct.pack_into("<I", result, image["relocation_count_offset"], len(remaining))
    old_uuid = uuid.UUID(bytes=data[image["uuid_offset"]:image["uuid_offset"] + 16])
    result[image["uuid_offset"]:image["uuid_offset"] + 16] = marker.bytes
    result = bytes(result)
    checked = image_layout(result)
    if (len(result) != len(data)
            or [r["raw"] for r in checked["relocations"]] != [r["raw"] for r in remaining]):
        raise ValueError("Probe changed unrelated relocation records or file size")
    return result, {
        "code_vm_address": hex(call_address), "code_file_offset": hex(code_offset),
        "original_instruction": binascii.hexlify(data[code_offset:code_offset + 5]).decode("ascii"),
        "replacement_instruction": binascii.hexlify(result[code_offset:code_offset + 5]).decode("ascii"),
        "removed_relocation_symbol": callee,
        "old_external_relocations": len(image["relocations"]),
        "new_external_relocations": len(remaining),
        "original_uuid": str(old_uuid), "probe_uuid": str(marker),
        "changed_file_bytes": sum(a != b for a, b in zip(data, result)),
    }

kernelcache.py：解析启动缓存及内嵌 UUID 
"""Inspect a Mavericks boot cache without loading or modifying it."""

from __future__ import print_function

import argparse
import base64
import json
import numbers
import struct
import uuid
from xml.etree import ElementTree
import zlib


def lzss_decode(data, expected_size):
    window = bytearray(b" " * 4078 + b"\0" * 18)
    position = 4078
    flags = 0
    index = 0
    output = bytearray()
    while index < len(data):
        flags >>= 1
        if not flags & 0x100:
            flags = data[index] | 0xFF00
            index += 1
        if flags & 1:
            if index >= len(data):
                raise ValueError("Truncated LZSS literal")
            values = (data[index],)
            index += 1
            for value in values:
                output.append(value)
                window[position] = value
                position = (position + 1) & 4095
        else:
            if index + 2 > len(data):
                raise ValueError("Truncated LZSS reference")
            reference = data[index] | ((data[index + 1] & 0xF0) << 4)
            length = (data[index + 1] & 15) + 3
            index += 2
            for offset in range(length):
                value = window[(reference + offset) & 4095]
                output.append(value)
                window[position] = value
                position = (position + 1) & 4095
        if len(output) > expected_size:
            raise ValueError("LZSS output exceeds declared size")
    if len(output) != expected_size:
        raise ValueError("LZSS output size mismatch")
    return bytes(output)


def uncompress(data):
    if data[:4] == b"\xca\xfe\xba\xbe":
        count = struct.unpack_from(">I", data, 4)[0]
        if count > 16 or 8 + count * 20 > len(data):
            raise ValueError("Invalid universal cache header")
        slices = []
        for index in range(count):
            cpu, subtype, offset, size, alignment = struct.unpack_from(
                ">5I", data, 8 + index * 20)
            if cpu == 0x01000007:
                if offset + size > len(data):
                    raise ValueError("Truncated universal cache")
                slices.append(data[offset:offset + size])
        if len(slices) != 1:
            raise ValueError("Expected one x86_64 cache slice")
        data = slices[0]
    if data[:4] == b"comp":
        if len(data) < 384 or data[4:8] != b"lzss":
            raise ValueError("Unsupported compressed cache format")
        checksum, size, compressed_size = struct.unpack_from(">3I", data, 8)
        if size > 512 * 1024 * 1024 or compressed_size != len(data) - 384:
            raise ValueError("Invalid compressed cache sizes")
        data = lzss_decode(bytearray(data[384:]), size)
        if zlib.adler32(data) & 0xFFFFFFFF != checksum:
            raise ValueError("Kernelcache Adler-32 mismatch")
    return data


def macho(data, base=0, limit=None):
    limit = len(data) if limit is None else limit
    if base < 0 or base + 32 > limit:
        raise ValueError("Truncated Mach-O header")
    header = struct.unpack_from("<8I", data, base)
    if header[0] != 0xFEEDFACF or header[1] != 0x01000007:
        raise ValueError("Expected x86_64 Mach-O")
    end = base + 32 + header[5]
    if end > limit or header[4] > header[5] // 8:
        raise ValueError("Invalid Mach-O commands")
    cursor = base + 32
    segments = []
    identifier = None
    for _ in range(header[4]):
        command, size = struct.unpack_from("<II", data, cursor)
        if size < 8 or size % 8 or cursor + size > end:
            raise ValueError("Invalid Mach-O command size")
        if command == 0x19:
            if size < 72:
                raise ValueError("Truncated Mach-O segment")
            fields = struct.unpack_from("<II16sQQQQiiII", data, cursor)
            segments.append({
                "name": fields[2].rstrip(b"\0").decode("ascii"),
                "address": fields[3], "offset": fields[5], "size": fields[6],
            })
        elif command == 0x1B:
            if size != 24 or identifier is not None:
                raise ValueError("Invalid Mach-O UUID command")
            identifier = str(uuid.UUID(bytes=bytes(data[cursor + 8:cursor + 24])))
        cursor += size
    if cursor != end:
        raise ValueError("Mach-O command length mismatch")
    return segments, identifier


def prelink_dictionary(xml):
    objects = {}

    def decode(node):
        reference = node.get("IDREF")
        if reference is not None:
            if reference not in objects:
                raise ValueError("Unresolved IOKit XML reference")
            return objects[reference]
        if node.tag == "dict":
            children = list(node)
            if len(children) % 2:
                raise ValueError("Invalid IOKit dictionary")
            value = {}
            for index in range(0, len(children), 2):
                if children[index].tag != "key":
                    raise ValueError("Missing IOKit dictionary key")
                key = decode(children[index])
                if key in value:
                    raise ValueError("Duplicate IOKit dictionary key")
                value[key] = decode(children[index + 1])
        elif node.tag == "array":
            value = [decode(child) for child in node]
        elif node.tag in ("key", "string"):
            value = node.text or ""
        elif node.tag == "integer":
            text = node.text or ""
            value = int(text, 16 if text.startswith("0x") else 10)
        elif node.tag == "data":
            value = base64.b64decode("".join((node.text or "").split()))
        elif node.tag in ("true", "false"):
            value = node.tag == "true"
        else:
            raise ValueError("Unsupported IOKit XML type: " + node.tag)
        identifier = node.get("ID")
        if identifier is not None:
            if identifier in objects:
                raise ValueError("Duplicate IOKit XML object ID")
            objects[identifier] = value
        return value

    return decode(ElementTree.fromstring(xml))


def inspect(cache, bundle_id, expected_uuid, include_inventory=False):
    data = uncompress(cache)
    segments, kernel_uuid = macho(data)
    metadata = [segment for segment in segments if segment["name"] == "__PRELINK_INFO"]
    if len(metadata) != 1:
        raise ValueError("Expected one prelink metadata segment")
    info = metadata[0]
    if info["offset"] + info["size"] > len(data):
        raise ValueError("Prelink metadata is outside the cache")
    xml = data[info["offset"]:info["offset"] + info["size"]].rstrip(b"\0")
    document = prelink_dictionary(xml)
    entries = document["_PrelinkInfoDictionary"]
    matches = [entry for entry in entries if entry.get("CFBundleIdentifier") == bundle_id]
    if len(matches) != 1:
        raise ValueError("Expected exactly one target bundle in the cache")
    entry = matches[0]
    address = entry["_PrelinkExecutableSourceAddr"]
    length = entry["_PrelinkExecutableSize"]
    if not isinstance(address, numbers.Integral) or not isinstance(length, numbers.Integral):
        raise ValueError("Prelinked executable address and size must be integers")
    locations = [segment["offset"] + address - segment["address"]
                 for segment in segments
                 if segment["address"] <= address
                 and address + length <= segment["address"] + segment["size"]]
    if len(locations) != 1:
        raise ValueError("Prelinked executable has no unique file-backed location")
    offset = locations[0]
    _, identifier = macho(data, offset, offset + length)
    if identifier != expected_uuid:
        raise ValueError("Cached driver UUID mismatch: %s, expected %s"
                         % (identifier, expected_uuid))
    result = {
        "bundle_id": bundle_id, "uuid": identifier,
        "bundle_path": entry.get("_PrelinkBundlePath"),
        "kernel_uuid": kernel_uuid, "bundle_count": len(entries),
        "uncompressed_bytes": len(data),
    }
    if include_inventory:
        inventory = {}
        for item in entries:
            name = item["CFBundleIdentifier"]
            if name in inventory:
                raise ValueError("Duplicate prelinked bundle identifier")
            inventory[name] = {
                "path": item.get("_PrelinkBundlePath"),
                "version": item.get("CFBundleVersion"),
            }
        result["inventory"] = inventory
    return result


def verify_inventory(original, candidate):
    before = original["inventory"]
    after = candidate["inventory"]
    for identifier, metadata in before.items():
        if after.get(identifier) != metadata:
            raise ValueError("Original cached bundle changed or disappeared: " + identifier)
    allowed = {
        "com.apple.filesystems.msdosfs": {
            "path": "/System/Library/Extensions/msdosfs.kext", "version": "1.9",
        },
    }
    additions = sorted(set(after) - set(before))
    for identifier in additions:
        if identifier not in allowed or after[identifier] != allowed[identifier]:
            raise ValueError("Unexpected cache addition: " + identifier)
    return additions


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("cache")
    parser.add_argument("--bundle-id", default="com.apple.kext.AMD7000Controller")
    parser.add_argument("--expect-uuid", required=True)
    args = parser.parse_args()
    with open(args.cache, "rb") as stream:
        result = inspect(stream.read(), args.bundle_id, args.expect_uuid)
    print(json.dumps(result, indent=2))


if __name__ == "__main__":
    main()
manage-dispclk600.py：目标机检查、部署、验证与回退 
"""Mavericks-only install, verify and rollback. Never reboot or hot-load a kext."""

import dispclk600

ROOT = "/var/db/d500-dispclk600"
EXTENSIONS = "/System/Library/Extensions"
BUNDLE = EXTENSIONS + "/AMD7000Controller.kext"
EXECUTABLE = "Contents/MacOS/AMD7000Controller"
CACHES = "/System/Library/Caches/com.apple.kext.caches"
BUNDLE_ID = "com.apple.kext.AMD7000Controller"
ORIGINAL_UUID = "5dd5f117-8f64-3b72-9e71-9f20af1c76ae"

def digest(path):
    result = hashlib.sha256()
    with open(path, "rb") as stream:
        for block in iter(lambda: stream.read(1024 * 1024), b""):
            result.update(block)
    return result.hexdigest()


def require_hash(path, expected):
    if digest(path) != expected:
        raise ValueError("Unexpected SHA-256: " + path)


def load_plist(data):
    if hasattr(plistlib, "loads"):
        return plistlib.loads(data)
    return plistlib.readPlistFromString(data)


def property_bytes(value):
    return getattr(value, "data", value)


def loaded_controller():
    core = ctypes.CDLL("/System/Library/Frameworks/CoreFoundation.framework/CoreFoundation")
    iokit = ctypes.CDLL("/System/Library/Frameworks/IOKit.framework/IOKit")
    iokit.OSKextCopyLoadedKextInfo.argtypes = [ctypes.c_void_p, ctypes.c_void_p]
    iokit.OSKextCopyLoadedKextInfo.restype = ctypes.c_void_p
    core.CFPropertyListCreateXMLData.argtypes = [ctypes.c_void_p, ctypes.c_void_p]
    core.CFPropertyListCreateXMLData.restype = ctypes.c_void_p
    core.CFDataGetLength.argtypes = [ctypes.c_void_p]
    core.CFDataGetLength.restype = ctypes.c_long
    core.CFDataGetBytePtr.argtypes = [ctypes.c_void_p]
    core.CFDataGetBytePtr.restype = ctypes.c_void_p
    core.CFRelease.argtypes = [ctypes.c_void_p]
    core.CFRelease.restype = None
    information = iokit.OSKextCopyLoadedKextInfo(None, None)
    if not information:
        raise RuntimeError("Cannot query loaded kexts")
    xml = None
    try:
        xml = core.CFPropertyListCreateXMLData(None, information)
        if not xml:
            raise RuntimeError("Cannot serialize loaded kext information")
        data = ctypes.string_at(core.CFDataGetBytePtr(xml), core.CFDataGetLength(xml))
        entry = load_plist(data)[BUNDLE_ID]
        return {
            "uuid": str(uuid.UUID(bytes=property_bytes(entry["OSBundleUUID"]))),
            "started": entry.get("OSBundleStarted") is True,
            "prelinked": entry.get("OSBundlePrelinked") is True,
        }
    finally:
        if xml:
            core.CFRelease(xml)
        core.CFRelease(information)


def check_environment():
    if sys.platform != "darwin" or os.geteuid() != 0:
        raise RuntimeError("Run with sudo on the target Mavericks Mac")
    for arguments, expected in (
            (["/usr/bin/sw_vers", "-productVersion"], b"10.9.5"),
            (["/usr/bin/sw_vers", "-buildVersion"], b"13F1911"),
            (["/usr/sbin/sysctl", "-n", "hw.model"], b"MacPro6,1")):
        if subprocess.check_output(arguments).strip() != expected:
            raise RuntimeError("Unsupported system or hardware")
    nodes = load_plist(subprocess.check_output(
        ["/usr/sbin/ioreg", "-a", "-l", "-r", "-c", "IOPCIDevice", "-w", "0"]))
    graphics = []

    def visit(entries):
        for entry in entries:
            if (property_bytes(entry.get("vendor-id")) == b"\x02\x10\0\0"
                    and entry.get("IOName") == "display"):
                graphics.append(entry)
            visit(entry.get("IORegistryEntryChildren", []))

    visit(nodes)
    if len(graphics) != 2 or any(property_bytes(entry.get("device-id")) != b"\x9e\x67\0\0"
                                 for entry in graphics):
        raise RuntimeError("Exactly two D500 display devices are required")


def inspect_cache(path, expected_uuid):
    with open(path, "rb") as stream:
        result = kernelcache.inspect(stream.read(), BUNDLE_ID, expected_uuid,
                                     include_inventory=True)
    if result["bundle_path"] != BUNDLE:
        raise ValueError("Unexpected controller path in boot cache")
    return result


def run(label, arguments):
    log_path = os.path.join(ROOT, label + ".log")
    with open(log_path, "wb") as log:
        process = subprocess.Popen(arguments, stdout=log, stderr=subprocess.STDOUT)
        start = time.time()
        waiter = threading.Event()
        while process.poll() is None:
            if time.time() - start > 360:
                process.terminate()
                for _ in range(20):
                    if process.poll() is not None:
                        break
                    waiter.wait(0.25)
                if process.poll() is None:
                    process.kill()
                process.wait()
                raise RuntimeError("Command timed out; see " + log_path)
            waiter.wait(0.25)
    if process.returncode:
        raise RuntimeError("Command failed; see " + log_path)


def replace_executable(source, expected_sha):
    target = os.path.join(BUNDLE, EXECUTABLE)
    temporary = target + ".dispclk600-new"
    if os.path.lexists(temporary):
        raise RuntimeError("Temporary executable already exists: " + temporary)
    try:
        run("replace", ["/usr/bin/ditto", "--rsrc", "--extattr", "--acl",
                        source, temporary])
        require_hash(temporary, expected_sha)
        os.chown(temporary, 0, 0)
        os.chmod(temporary, 0o755)
        os.rename(temporary, target)
        require_hash(target, expected_sha)
    finally:
        if os.path.isfile(temporary) and not os.path.islink(temporary):
            os.unlink(temporary)


def backup_metadata():
    info = os.lstat(ROOT)
    if not stat.S_ISDIR(info.st_mode) or info.st_uid != 0 or info.st_mode & 0o077:
        raise RuntimeError("Backup directory must be root-owned with mode 0700")
    with open(os.path.join(ROOT, "backup.json")) as stream:
        metadata = json.load(stream)
    require_hash(os.path.join(ROOT, "original.kext", EXECUTABLE), dispclk600.SOURCE_SHA256)
    require_hash(os.path.join(ROOT, "caches/Startup/kernelcache"), metadata["cache_sha256"])
    inspect_cache(os.path.join(ROOT, "caches/Startup/kernelcache"), ORIGINAL_UUID)
    return metadata


def rollback():
    metadata = backup_metadata()
    if (digest(os.path.join(BUNDLE, EXECUTABLE)) == dispclk600.SOURCE_SHA256
            and digest(os.path.join(CACHES, "Startup/kernelcache")) == metadata["cache_sha256"]):
        inspect_cache(os.path.join(CACHES, "Startup/kernelcache"), ORIGINAL_UUID)
        for path, values in metadata["directory_times"].items():
            os.utime(path, tuple(values))
        print("Original file and caches restored already; running driver unchanged.")
        return
    temporary = CACHES + ".dispclk600-restore"
    displaced = CACHES + ".dispclk600-displaced"
    if os.path.lexists(temporary) or os.path.lexists(displaced):
        raise RuntimeError("Unfinished cache restore; use the documented recovery procedure")
    run("restore-cache-copy", ["/usr/bin/ditto", "--rsrc", "--extattr", "--acl",
                               os.path.join(ROOT, "caches"), temporary])
    require_hash(os.path.join(temporary, "Startup/kernelcache"), metadata["cache_sha256"])
    replace_executable(os.path.join(ROOT, "original.kext", EXECUTABLE),
                       dispclk600.SOURCE_SHA256)
    os.rename(CACHES, displaced)
    try:
        os.rename(temporary, CACHES)
    except Exception:
        os.rename(displaced, CACHES)
        raise
    for path, values in metadata["directory_times"].items():
        os.utime(path, tuple(values))
    inspect_cache(os.path.join(CACHES, "Startup/kernelcache"), ORIGINAL_UUID)
    require_hash(os.path.join(CACHES, "Startup/kernelcache"), metadata["cache_sha256"])
    run("rollback-sync", ["/bin/sync"])
    print("Original file and caches restored. Running driver unchanged; reboot manually.")


def install(candidate):
    require_hash(candidate, dispclk600.EXPECTED_OUTPUT_SHA256)
    require_hash(os.path.join(BUNDLE, EXECUTABLE), dispclk600.SOURCE_SHA256)
    loaded = loaded_controller()
    if loaded != {"uuid": ORIGINAL_UUID, "started": True, "prelinked": True}:
        raise RuntimeError("Boot the matching original driver before installing")
    original_cache = inspect_cache(os.path.join(CACHES, "Startup/kernelcache"), ORIGINAL_UUID)
    cache_sha = digest(os.path.join(CACHES, "Startup/kernelcache"))
    directory_times = {path: (os.stat(path).st_atime, os.stat(path).st_mtime)
                       for path in (BUNDLE, EXTENSIONS)}
    os.umask(0o077)
    os.mkdir(ROOT, 0o700)
    for source, destination in ((BUNDLE, "original.kext"), (CACHES, "caches"),
                                (BUNDLE, "candidate.kext")):
        run("backup-" + destination, ["/usr/bin/ditto", "--rsrc", "--extattr", "--acl",
                                      source, os.path.join(ROOT, destination)])
    require_hash(os.path.join(ROOT, "original.kext", EXECUTABLE), dispclk600.SOURCE_SHA256)
    require_hash(os.path.join(ROOT, "caches/Startup/kernelcache"), cache_sha)
    metadata = {"cache_sha256": cache_sha, "directory_times": directory_times}
    with open(os.path.join(ROOT, "backup.json"), "w") as stream:
        json.dump(metadata, stream, indent=2)
    with open(os.path.join(ROOT, "SHA256SUMS"), "w") as stream:
        stream.write(dispclk600.SOURCE_SHA256 + "  original.kext/" + EXECUTABLE + "\n")
        stream.write(cache_sha + "  caches/Startup/kernelcache\n")
    staged = os.path.join(ROOT, "candidate.kext", EXECUTABLE)
    run("stage", ["/usr/bin/ditto", "--rsrc", "--extattr", "--acl", candidate, staged])
    os.chown(staged, 0, 0)
    os.chmod(staged, 0o755)
    require_hash(staged, dispclk600.EXPECTED_OUTPUT_SHA256)
    diagnostic = ["/usr/bin/kextutil", "-no-load", "-print-diagnostics", "-no-caches",
                  "-no-loaded-check", "-verbose", "3", "-arch", "x86_64", "--"]
    run("preflight-original", diagnostic + [BUNDLE])
    run("preflight-candidate", diagnostic + [os.path.join(ROOT, "candidate.kext")])
    require_hash(os.path.join(BUNDLE, EXECUTABLE), dispclk600.SOURCE_SHA256)
    require_hash(os.path.join(CACHES, "Startup/kernelcache"), cache_sha)
    run("backup-sync", ["/bin/sync"])
    try:
        replace_executable(staged, dispclk600.EXPECTED_OUTPUT_SHA256)
        os.utime(BUNDLE, None)
        os.utime(EXTENSIONS, None)
        run("prelinked-kernel", ["/usr/sbin/kextcache", "-verbose", "3",
                                 "-system-prelinked-kernel"])
        run("system-caches", ["/usr/sbin/kextcache", "-verbose", "3", "-system-caches"])
        result = inspect_cache(os.path.join(CACHES, "Startup/kernelcache"), PATCHED_UUID)
        additions = kernelcache.verify_inventory(original_cache, result)
        require_hash(os.path.join(BUNDLE, EXECUTABLE), dispclk600.EXPECTED_OUTPUT_SHA256)
        run("sync", ["/bin/sync"])
    except BaseException:
        print("Install failed; restoring original file and caches.")
        rollback()
        raise
    print("Patched cache verified. Additional stock cache entries: " + repr(additions))
    print("Ready for a manual reboot. Running driver has not been hot-loaded.")


def verify(expected):
    sha = dispclk600.EXPECTED_OUTPUT_SHA256 if expected == "patched" else dispclk600.SOURCE_SHA256
    identifier = PATCHED_UUID if expected == "patched" else ORIGINAL_UUID
    require_hash(os.path.join(BUNDLE, EXECUTABLE), sha)
    result = loaded_controller()
    if result != {"uuid": identifier, "started": True, "prelinked": True}:
        raise RuntimeError("Loaded UUID/start/prelink mismatch: " + repr(result))
    inspect_cache(os.path.join(CACHES, "Startup/kernelcache"), identifier)
    print(json.dumps(result, indent=2))
    print("Disk, boot cache and loaded UUID match; inspect physical output and flicker separately.")


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("action", choices=("install", "verify", "rollback"))
    parser.add_argument("--candidate")
    parser.add_argument("--expect", choices=("original", "patched"), default="patched")
