Hyper-V

面向 Windows 10/11 Pro/Enterprise 与 Windows Server。命令默认在管理员 PowerShell 中执行。

status

# CPU / 固件虚拟化支持
Get-ComputerInfo -Property HyperVRequirement*

# Hyper-V PowerShell 模块
Get-Command -Module Hyper-V

# 主机默认配置
Get-VMHost | Format-List *

# VM 状态
Get-VM | Sort-Object Name | Format-Table Name, State, CPUUsage, MemoryAssigned, Uptime

功能状态按宿主系统选择命令：

# Windows 10/11
Get-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V-All
# Windows Server
Get-WindowsFeature -Name Hyper-V

services

Get-Service vmms, vmcompute | Format-Table Name, Status, DisplayName

仅在排障需要时重启对应服务，以下两项按需单独执行：

# 中断 Hyper-V VM 管理操作
Restart-Service vmms
# 影响 WSL / Windows Sandbox / 容器等 Host Compute Service 使用者
Restart-Service vmcompute

virtual machines

power and console

Start-VM -Name "Win11"
Stop-VM -Name "Win11"
Restart-VM -Name "Win11"
vmconnect.exe localhost "Win11"

保存到磁盘与从 Saved 状态恢复：

Save-VM -Name "Win11"
Start-VM -Name "Win11"

暂停与从 Paused 状态恢复：

Suspend-VM -Name "Win11"
Resume-VM -Name "Win11"

强制断电，不走来宾系统关机流程：

Stop-VM -Name "Win11" -TurnOff

automatic actions

Set-VM -Name "Win11" `
  -AutomaticStartAction StartIfRunning `
  -AutomaticStartDelay 30 `
  -AutomaticStopAction Save

Get-VM -Name "Win11" | Select-Object Name, AutomaticStartAction, AutomaticStartDelay, AutomaticStopAction

cpu and memory

Set-VMProcessor -VMName "Win11" -Count 6

Set-VMMemory -VMName "Win11" `
  -DynamicMemoryEnabled $true `
  -MinimumBytes 2GB `
  -StartupBytes 4GB `
  -MaximumBytes 12GB

Get-VMProcessor -VMName "Win11"
Get-VMMemory -VMName "Win11"

嵌套虚拟化需要先关闭 VM：

Stop-VM -Name "Win11"
Set-VMProcessor -VMName "Win11" -ExposeVirtualizationExtensions $true

network adapters

Get-VMNetworkAdapter -VMName "Win11" | Format-List *

Connect-VMNetworkAdapter -VMName "Win11" -SwitchName "External"
Disconnect-VMNetworkAdapter -VMName "Win11"

Add-VMNetworkAdapter -VMName "Win11" -Name "Lab" -SwitchName "LabNAT"
Remove-VMNetworkAdapter -VMName "Win11" -Name "Lab"

读取 VM 内 IP 地址依赖集成服务：

Get-VMNetworkAdapter -VMName "Win11" | Select-Object VMName, SwitchName, IPAddresses

VLAN 与 MAC Spoofing：

Set-VMNetworkAdapterVlan -VMName "Win11" -Access -VlanId 20
Set-VMNetworkAdapterVlan -VMName "Win11" -Untagged

Set-VMNetworkAdapter -VMName "Win11" -MacAddressSpoofing On

virtual disks

attach disk

New-VHD -Path "D:\VMs\Data.vhdx" -SizeBytes 200GB -Dynamic
Add-VMHardDiskDrive -VMName "Win11" -Path "D:\VMs\Data.vhdx"

Get-VMHardDiskDrive -VMName "Win11"
Get-VHD -Path "D:\VMs\Data.vhdx"

resize and convert

以下操作按需单独执行，先关闭使用该磁盘的 VM。扩容 VHDX 后，还需要在来宾系统内扩展分区。

Resize-VHD -Path "D:\VMs\Win11\Win11.vhdx" -SizeBytes 120GB

# 动态 / 固定格式转换
Convert-VHD -Path "D:\VMs\Win11\Win11.vhdx" -DestinationPath "D:\VMs\Win11\Win11-fixed.vhdx" -VHDType Fixed

compact

动态 VHDX 要执行真正的 Full 压缩，需先只读挂载。未只读挂载时，VHDX 的 Full 会退化为 Prezeroed；压缩成功也不保证文件变小。

$VhdPath = "D:\VMs\Win11\Win11.vhdx"
Mount-VHD -Path $VhdPath -ReadOnly -ErrorAction Stop
try {
  Optimize-VHD -Path $VhdPath -Mode Full
} finally {
  Dismount-VHD -Path $VhdPath
}

条件见 Optimize-VHD。

mount offline

Mount-VHD -Path "D:\VMs\Win11\Win11.vhdx" -ReadOnly
Get-Disk | Where-Object IsOffline -eq $false
Dismount-VHD -Path "D:\VMs\Win11\Win11.vhdx"

checkpoints

检查点适合升级、实验前短期回滚，不等于备份。长期保留检查点会拖慢 IO，并让差异盘链条变复杂。

Set-VM -Name "Win11" -CheckpointType ProductionOnly
Set-VM -Name "Win11" -AutomaticCheckpointsEnabled $false

Checkpoint-VM -Name "Win11" -SnapshotName "before-upgrade"
Get-VMSnapshot -VMName "Win11"

Restore-VMSnapshot -VMName "Win11" -Name "before-upgrade" -Confirm:$false
Remove-VMSnapshot -VMName "Win11" -Name "before-upgrade"

删除所有检查点：

Get-VMSnapshot -VMName "Win11" | Remove-VMSnapshot

switches

list switches

Get-VMSwitch | Format-Table Name, SwitchType, NetAdapterInterfaceDescription
Get-NetAdapter | Format-Table Name, Status, LinkSpeed, InterfaceDescription

external switch

外部交换机会接管物理网卡，并在宿主机上创建 vEthernet (...) 适配器；修改时宿主网络可能短暂中断。

New-VMSwitch -Name "External" -NetAdapterName "Ethernet" -AllowManagementOS $true

旧案例中 WSL 2 mirrored 与 Hyper-V 外部交换机共存时出现过网络故障，尚未隔离单个原因，见 WSL 网络调查。

internal and private switches

# 宿主机与 VM 可通信，外部网络不直通
New-VMSwitch -Name "Internal" -SwitchType Internal

# 只有 VM 之间可通信，宿主机也不能直接访问
New-VMSwitch -Name "Private" -SwitchType Private

internal switch and nat

Hyper-V 的 Internal Switch 不自带 DHCP，VM 内需要手动设置静态 IP，或另起 DHCP 服务。

$SwitchName = "LabNAT"
$Gateway = "192.168.100.1"
$Prefix = "192.168.100.0/24"

New-VMSwitch -Name $SwitchName -SwitchType Internal
New-NetIPAddress -IPAddress $Gateway -PrefixLength 24 -InterfaceAlias "vEthernet ($SwitchName)"
New-NetNat -Name $SwitchName -InternalIPInterfaceAddressPrefix $Prefix

Get-NetNat

VM 内示例：

IP:      192.168.100.10
Mask:    255.255.255.0
Gateway: 192.168.100.1
DNS:     1.1.1.1 / 8.8.8.8

端口转发：

Add-NetNatStaticMapping -NatName "LabNAT" -Protocol TCP `
  -ExternalIPAddress 0.0.0.0 -ExternalPort 2222 `
  -InternalIPAddress 192.168.100.10 -InternalPort 22

Get-NetNatStaticMapping -NatName "LabNAT"

清理 NAT：

Get-NetNatStaticMapping -NatName "LabNAT" | Remove-NetNatStaticMapping
Remove-NetNat -Name "LabNAT" -Confirm:$false
Remove-NetIPAddress -InterfaceAlias "vEthernet (LabNAT)" -IPAddress 192.168.100.1 -Confirm:$false
Remove-VMSwitch -Name "LabNAT" -Force

rename and remove switches

Rename-VMSwitch -Name "External" -NewName "LAN"
Remove-VMSwitch -Name "LAN" -Force

create vm

先选一组来宾参数，再执行公共创建命令。Windows 11：

$VM = "Win11"
$Iso = "D:\ISO\Win11.iso"
$CPU = 4
$StartupMemory = 4GB
$MinimumMemory = 4GB
$MaximumMemory = 8GB
$DiskSize = 80GB
$SecureBootTemplate = "MicrosoftWindows"
$EnableTPM = $true

Linux（以 Ubuntu 为例）：

$VM = "Ubuntu"
$Iso = "D:\ISO\ubuntu-26.04-live-server-amd64.iso"
$CPU = 2
$StartupMemory = 2GB
$MinimumMemory = 1GB
$MaximumMemory = 6GB
$DiskSize = 40GB
$SecureBootTemplate = "MicrosoftUEFICertificateAuthority"
$EnableTPM = $false

公共创建命令：先用 Get-VMSwitch 查询，将 $Switch 改为已有交换机名称。Windows 客户端可用 Default Switch，Windows Server 需先创建外部交换机或 Internal + NAT。

$Root = Join-Path "D:\VMs" $VM
$Switch = "External"
Get-VMSwitch -Name $Switch -ErrorAction Stop | Out-Null
if (-not (Test-Path -LiteralPath $Iso -PathType Leaf)) {
  throw "ISO 不存在：$Iso"
}

New-Item -Path $Root -ItemType Directory -Force | Out-Null

New-VM -Name $VM `
  -Generation 2 `
  -MemoryStartupBytes $StartupMemory `
  -NewVHDPath "$Root\$VM.vhdx" `
  -NewVHDSizeBytes $DiskSize `
  -SwitchName $Switch `
  -ErrorAction Stop

Set-VMProcessor -VMName $VM -Count $CPU
Set-VMMemory -VMName $VM -DynamicMemoryEnabled $true `
  -MinimumBytes $MinimumMemory -StartupBytes $StartupMemory -MaximumBytes $MaximumMemory
Set-VMFirmware -VMName $VM -EnableSecureBoot On -SecureBootTemplate $SecureBootTemplate
Add-VMDvdDrive -VMName $VM -Path $Iso
Set-VMFirmware -VMName $VM -FirstBootDevice (Get-VMDvdDrive -VMName $VM)
Set-VM -Name $VM -AutomaticCheckpointsEnabled $false

if ($EnableTPM) {
  Set-VMKeyProtector -VMName $VM -NewLocalKeyProtector
  Enable-VMTPM -VMName $VM
  Get-VMTPM -VMName $VM
}

若 Linux 仍因 Secure Boot 无法引导，可关闭它做对照排查：

Set-VMFirmware -VMName "Ubuntu" -EnableSecureBoot Off

$Config = "E:\HyperV-Export\Win11\Virtual Machines\<GUID>.vmcx"

Import-VM -Path $Config `

  -VirtualMachinePath "D:\VMs\Win11-Imported" `

Compare-VM -Path "E:\HyperV-Export\Win11\Virtual Machines\<GUID>.vmcx"

Move-VMStorage -VMName "Win11" -DestinationStoragePath "E:\VMs\Win11"

Copy-VMFile -VMName "Win11" `

PowerShell Direct 不依赖网络，但 guest 必须是 Windows 且支持 Hyper-V 集成组件：

$Cred = Get-Credential
Enter-PSSession -VMName "Win11" -Credential $Cred

Invoke-Command -VMName "Win11" -Credential $Cred -ScriptBlock {
  hostname
  Get-ComputerInfo -Property OsName, OsVersion
}

host setup

feature

按宿主系统选择一个启用命令。Windows 10/11：

Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V -All
Restart-Computer

Windows Server：

Install-WindowsFeature -Name Hyper-V -IncludeManagementTools -Restart

hypervisor

启用或恢复开机加载，重启后生效：

bcdedit /set hypervisorlaunchtype auto
Restart-Computer

排查冲突时关闭，重启后生效；此设置会一直保留，恢复时执行上面的 auto 命令。关闭后依赖 hypervisor 的 VM、WSL 2 和 Sandbox 等无法使用。

bcdedit /set hypervisorlaunchtype off
Restart-Computer
